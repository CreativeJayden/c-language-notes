## lv_label_set_text

功能：设置某个 label 组件的内容。

```c
void lv_label_set_text(lv_obj_t * label, const char * text)
```

- `label`：要设置的 label 组件。
- `text`：要显示的内容。
- 返回值：无。

```c
lv_label_set_text(guider_ui.screen_label_year, "2026-11-23");
```

## lv_imgbtn_set_state

功能：设置某个 imgbtn 组件的状态。

```c
void lv_imgbtn_set_state(lv_obj_t * imgbtn, lv_btn_state_t state)
```

| 状态 | 图标含义 |
| --- | --- |
| `LV_BTN_STATE_RELEASED` | 三角形 |
| `LV_BTN_STATE_PRESSED` | 双竖线 |
| `LV_BTN_STATE_CHECKED_RELEASED` | 双竖线 |
| `LV_BTN_STATE_CHECKED_PRESSED` | 三角形 |

```c
lv_imgbtn_set_state(
    guider_ui.screen_imgbtn_stop_or_start,
    LV_BTN_STATE_CHECKED_RELEASED
);
```

修改代码前，先找到每个控件的名字，方便区分。
