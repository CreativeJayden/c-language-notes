## 在 LVGL 工程中创建线程

LVGL 界面默认在一个线程里刷新。如果要持续更新时间，可以在工程中创建独立线程定期刷新 label。`main.c` 中的步骤：

1. 包含头文件。
2. 定义线程号。
3. 声明线程回调函数。
4. 创建线程。
5. 编写线程回调函数。
6. 修改 Makefile，链接线程库。

Linux 下使用 `pthread` 创建线程时，编译和链接需要线程库：

```text
lpthread
```

线程回调函数是线程创建成功后执行的内容，可以在其中更新时间 label。

## MP3 播放器界面移植

把不带界面的 MP3 控制逻辑移植到 LVGL 时，控制目标从终端按键变成界面组件：

1. 上一首、下一首、暂停、继续，需要严苛测试，不能有 bug。
2. 时间显示。
3. 歌名显示，使用字库移植实现。
4. 自由发挥。

界面状态切换时，用 `lv_imgbtn_set_state` 更新播放/暂停按钮图标；歌曲切换时，用 `lv_label_set_text` 更新歌名。

## 字库移植

1. 找到字体转换软件并打开。
2. 在 Windows 中找到字体，复制到桌面备用。
3. 点击选择字体。
4. 加入常用汉字。
5. 点击开始转换，保存到桌面。
6. 等待转换成功，得到字库文件。
7. 把字库文件复制到工程中。
8. 打开工程做相应改动。

在代码中：

1. 声明自己字库的名字。
2. 修改界面中的歌名 label 组件使用自己的字库。
3. 再次编译运行，即可看到汉字显示。

一种常见使用方式：

```c
#include "lv_font_simsun_16_cjk.h"

lv_font_t lv_font_simsun_16_cjk;
lv_label_set_style(label, LV_LABEL_PART_MAIN, &lv_font_simsun_16_cjk);
```

> 字库文件名和函数写法应按实际生成的字库文件为准，截图中的名字是示例。
