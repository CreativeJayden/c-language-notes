## LVGL 是什么

LVGL（Light and Versatile Graphics Library）是一个用于嵌入式系统的开源图形库。

它提供了一套功能丰富的图形界面组件，适用于没有操作系统或带操作系统的嵌入式平台。

LVGL 的主要特点：

- 轻量级：适用于资源受限的嵌入式设备。
- 跨平台：可以在裸机环境下运行，也可以在 FreeRTOS、RT-Thread、Linux 等操作系统上运行。
- 组件丰富：提供按钮、图表、列表、滑块等图形组件。
- 支持多种显示接口：可以直接与单色、彩色 LCD/TFT 等显示硬件接口。
- 易于使用：有良好的文档和示例代码。

> `Qt -> C++` 属于驱动阶段内容，本页只记录 LVGL 基础。

## 安装依赖

```bash
sudo apt-get update
sudo apt-get install libsdl2-dev
```

如果提示“暂时不能解析域名”，检查 Ubuntu 是否联网或换源。

## 安装 GUI Guider

```bash
sudo dpkg -i Gui-Guider-Setup-1.2.1-GA.deb
```

如果安装时报依赖不存在，先修复依赖：

```bash
sudo apt-get install -f
```

然后再重新执行安装命令。

安装完成后，可以在应用程序中搜索 `gui` 打开 GUI Guider。
