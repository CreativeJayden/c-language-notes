## 基本流程

1. 打开 GUI Guider。
2. 设置中文。
3. 放置图片，设置图片大小和位置。
4. 设计界面。
5. 点击“生成代码”。
6. 运行模拟器预览界面。

设计好界面后，点击生成代码可以把界面生成一个工程。运行模拟器生成的是仅供预览的界面。

## 生成的工程目录

最核心的文件夹是 `lvgl-simulator`：

| 路径 | 作用 |
| --- | --- |
| `lvgl-simulator` | 存放 `main.c`、`Makefile` 和编译生成的可执行程序 |
| `build/bin` | 编译成功后的可执行程序位置 |
| `custom` | 存放用户自己的 `.c` 和 `.h` 代码 |
| `generated` | 存放图片的模、汉字的模、事件代码 |
| `generated/events_init.c` | 事件代码 |
| `generated/setup_scr_screen.c` | 设计界面后生成的代码 |
| `lvgl` | LVGL 图形库源码，课件说明不需要修改 |
