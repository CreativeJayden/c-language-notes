## 时间相关命令

```bash
date
cal
cal 年
cal 月 年
```

## time

```c
time_t time(time_t *tloc);
```

头文件：

```c
#include <time.h>
```

功能：获取从 1970 年 1 月 1 日 0 点 0 分 0 秒到当前的秒数。

```c
time_t t = time(NULL);
```

```c
time_t t;
time(&t);
```

## struct tm

```c
struct tm
{
    int tm_sec;
    int tm_min;
    int tm_hour;
    int tm_mday;
    int tm_mon;
    int tm_year;
    int tm_wday;
    int tm_yday;
    int tm_isdst;
};
```

| 字段 | 含义 |
| --- | --- |
| `tm_sec` | 秒，0-60 |
| `tm_min` | 分，0-59 |
| `tm_hour` | 时，0-23 |
| `tm_mday` | 一月中的第几天，1-31 |
| `tm_mon` | 月，0-11 |
| `tm_year` | 年份减去 1900 |
| `tm_wday` | 星期，0-6，星期日为 0 |
| `tm_yday` | 一年中的第几天，0-365 |

## localtime 和 gmtime

```c
struct tm *localtime(const time_t *timep);
struct tm *gmtime(const time_t *timep);
```

- `localtime`：转换为本地时间。
- `gmtime`：转换为格林尼治时间。

```c
struct tm *ltime = localtime(&t);
```

显示年份和月份时：

```c
year = tm->tm_year + 1900;
month = tm->tm_mon + 1;
```

## ctime 和 asctime

```c
char *ctime(const time_t *timep);
char *asctime(const struct tm *tm);
```

`ctime` 把秒数转换为时间字符串；`asctime` 把 `struct tm` 转换为时间字符串。

## strftime

```c
size_t strftime(char *s, size_t max, const char *format,
                const struct tm *tm);
```

```c
char buf[50] = {0};
strftime(buf, sizeof(buf), "%F %T", ltime);
```

## 定时创建文件

```c
t = time(NULL);
ltime = localtime(&t);

strftime(file_name, sizeof(file_name), "%F %T", ltime);
strcat(file_name, ".txt");

fd = open(file_name, O_RDWR | O_TRUNC | O_CREAT, 0666);
cnt++;
sprintf(file_content, "这是我创建的第%d个文件", cnt);

write(fd, file_content, strlen(file_content));
close(fd);
sleep(5);
```

这类定时任务的固定延迟用 `sleep` 实现。
