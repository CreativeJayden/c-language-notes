## 为什么学习非缓冲区文件操作

管道文件、套接字文件等特殊文件使用 `int` 类型的文件描述符，无法使用 `fopen`、`fclose` 这一套标准库函数。

非缓冲文件的基本流程：

```text
打开文件 -> 读写文件 -> 关闭文件
```

主要函数：

```text
open close read write lseek
```

## open

```c
int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);
```

头文件：

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
```

- 成功：返回文件描述符。课件示例中普通文件从 `3` 开始。
- 失败：返回 `-1`。
- `0`：标准输入。
- `1`：标准输出。
- `2`：标准错误。

三个必选打开方式：

| 选项 | 含义 |
| --- | --- |
| `O_RDONLY` | 只读 |
| `O_WRONLY` | 只写 |
| `O_RDWR` | 读写 |

可选标志使用按位或 `|` 组合：

| 选项 | 含义 |
| --- | --- |
| `O_APPEND` | 追加写 |
| `O_CREAT` | 文件不存在时创建 |
| `O_TRUNC` | 清空已有文件内容 |
| `O_EXCL` | 与创建配合，文件已存在时失败并设置 `errno` |
| `O_NOCTTY` | 不把终端设备作为控制终端 |
| `O_NONBLOCK` | 以非阻塞方式打开 |

使用 `O_CREAT` 时必须提供第三个参数 `mode`。

实际权限为：

```text
mode & (~umask)
```

```c
int fd = open("1.txt", O_RDWR | O_CREAT | O_TRUNC, 0666);
```

## close

```c
int close(int fd);
```

- 成功返回 `0`。
- 失败返回 `-1`。

## write

```c
ssize_t write(int fd, const void *buf, size_t count);
```

结构体大小使用 `sizeof`，字符串长度使用 `strlen`。

## read

```c
ssize_t read(int fd, void *buf, size_t count);
```

- `buf`：存放读到的内容。
- `count`：读取大小。
- 成功：返回读到的字节数。
- 失败：返回 `-1`。

## lseek

```c
off_t lseek(int fd, off_t offset, int whence);
```

参考位置：

| 参数 | 含义 |
| --- | --- |
| `SEEK_SET` | 文件开头 |
| `SEEK_CUR` | 当前位置 |
| `SEEK_END` | 文件末尾 |

## 实现 cp

```bash
./a.out 1.c 2.c
```

```c
if (argc != 3)
{
    printf("输入有误\n");
    return -1;
}

int fd1 = open(argv[1], O_RDONLY);
int fd2 = open(argv[2], O_RDWR | O_CREAT | O_TRUNC, 0666);

off_t size = lseek(fd1, 0, SEEK_END);
lseek(fd1, 0, SEEK_SET);

char *p = malloc(size);
memset(p, 0, size);
read(fd1, p, size);
write(fd2, p, size);

free(p);
close(fd1);
close(fd2);
```

常见实现方法：

1. 读一个写一个。
2. 读一些写一些。
3. 读全部写全部，只适合已知文件大小很小或学习演示。
4. 先用 `lseek` 求文件大小，再用 `malloc` 开辟空间。

“读一些写一些”按本次实际读到的字节数写入：

```c
while ((ret = read(fd1, buf, sizeof(buf))) > 0)
{
    write(fd2, buf, ret);
}
```
