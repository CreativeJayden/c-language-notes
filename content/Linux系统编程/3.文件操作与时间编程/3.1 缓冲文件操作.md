## 基于缓冲区的文件操作

C 标准库通过 `FILE *` 管理文件流：

```c
#include <stdio.h>

FILE *fp;
```

每运行一个程序，默认打开三个文件流：

| 文件流 | 作用 |
| --- | --- |
| `stdin` | 标准输入 |
| `stdout` | 标准输出 |
| `stderr` | 标准错误 |

## 常用函数

```c
fopen/fclose
fputc/fgetc
fputs/fgets
fprintf/fscanf
fwrite/fread
rewind/fseek/ftell/feof
```

## 缓冲区

`printf` 也是基于缓冲区的函数。输出缓冲区的刷新条件：

1. 遇到换行符 `\n`。
2. 程序正常结束。
3. 缓冲区满，示例大小是 1024 字节。
4. 手动调用 `fflush`。

```c
#include <stdio.h>

int fflush(FILE *stream);
```

## 结构体文件读写

可以用结构体保存账号和密码，再整体写入文件：

```c
typedef struct
{
    int account;
    char passwd[20];
} USER;

USER info = {0};
FILE *fp = fopen(argv[1], "w+");

if (fp == NULL)
{
    perror("fopen");
    return -1;
}

fwrite(&info, sizeof(info), 1, fp);
fclose(fp);
```

读取：

```c
fp = fopen(argv[1], "r");
fread(&info, sizeof(info), 1, fp);
fclose(fp);
```

结构体传大小使用 `sizeof`，字符串传长度使用 `strlen`。

## 登录校验

写入账号和密码后，可以读回结构体并与输入比较：

```c
int chance = 3;

while (chance > 0)
{
    scanf("%d%s", &id, mima);

    if (id == info.account && strcmp(mima, info.passwd) == 0)
    {
        printf("账号密码正确\n");
        break;
    }

    chance--;
    printf("账号密码输入错误，还剩%d次机会\n", chance);
}
```

这里用 `chance` 单独保存剩余次数，不要直接对循环变量再减一次。

## 缓冲区与非缓冲区

- 缓冲区操作先把数据放入内存缓冲区，减少直接访问磁盘的次数。
- 非缓冲区操作直接访问磁盘。
- 频繁 I/O 会影响性能，缓冲区的性能和效率通常更好。
- 非缓冲区适用于实时性要求较高的场景。
