## 什么是信号

信号类似于通知，是一种软中断机制。

中断是 CPU 的异常机制之一，特点是“快进快出”：正在执行一件事情时，突然发生另一件事情，先去处理突发事件，再返回原来的工作。

## Linux 信号数量

Linux 共有 62 个信号：

- 前 31 个信号继承自 Unix，称为老信号。
- 后 31 个信号是 Linux 新增加的。

## 重点信号

| 信号编号 | 名称 | 含义 |
| --- | --- | --- |
| `2` | `SIGINT` | `Ctrl + C` 结束进程 |
| `3` | `SIGQUIT` | `Ctrl + \` 结束进程 |
| `9` | `SIGKILL` | 杀死进程 |
| `17` | `SIGCHLD` | 子进程状态改变 |
| `18` | `SIGCONT` | 继续运行 |
| `19` | `SIGSTOP` | 暂停 |

子进程暂停、继续、结束等状态改变时，会触发 17 号信号。

## kill 命令

```bash
kill -信号 进程号
```

示例：

```bash
kill -9 1234
```

## 信号处理方式

| 处理方式 | 含义 |
| --- | --- |
| `SIG_DFL` | 默认处理 |
| `SIG_IGN` | 忽略处理 |
| 自定义函数 | 捕获处理 |

`SIGKILL(9)` 和 `SIGSTOP(19)` 不能被捕捉，也不能被忽略。
