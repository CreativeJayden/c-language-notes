## raise

```c
int raise(int sig);
```

头文件：

```c
#include <signal.h>
```

功能：自己给自己发送信号。

## kill

```c
int kill(pid_t pid, int sig);
```

头文件：

```c
#include <sys/types.h>
#include <signal.h>
```

功能：向某个进程发送信号。

## signal

```c
typedef void (*sighandler_t)(int);

sighandler_t signal(int signum, sighandler_t handler);
```

自定义捕获函数：

```c
void Sig_handler(int sig)
{
    printf("%d 号信号被捕获\n", sig);
}

signal(17, Sig_handler);
```

## 子进程控制示例

```c
signal(17, Sig_handler);

pid_t pid = fork();

if (pid == 0)
{
    while (1)
    {
        printf("i am son process\n");
        sleep(1);
    }
}
else if (pid > 0)
{
    char ch;
    while (1)
    {
        ch = getchar();
        switch (ch)
        {
        case 's':
            kill(pid, 19);
            break;
        case 'c':
            kill(pid, 18);
            break;
        case 'q':
            kill(pid, 9);
            break;
        }
    }
}
```

| 按键 | 操作 |
| --- | --- |
| `s` | 暂停子进程 |
| `c` | 继续子进程 |
| `q` | 杀死子进程 |

## MP3 播放器控制

| 按键 | 功能 |
| --- | --- |
| `s` | 暂停 |
| `c` | 继续 |
| `l` | 上一首 |
| `n` | 下一首 |
| `q` | 退出 |

实现思路：

1. 获取歌单。
2. 创建子进程，使用 `exec` 函数族调用 `mpg123` 播放歌曲。
3. 父进程负责菜单。
4. 下一首时杀死正在播放的子进程，再创建新子进程播放下一首。
5. 使用 `waitpid` 处理子进程。
6. 暂停、继续、切换歌曲都会触发 17 号信号。

播放器退出时要在进程退出清理函数中恢复终端光标和显示状态。
