## 获取文件属性

```c
int stat(const char *pathname, struct stat *statbuf);
int fstat(int fd, struct stat *statbuf);
int lstat(const char *pathname, struct stat *statbuf);
```

头文件：

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <unistd.h>
```

三者区别：

| 函数 | 区别 |
| --- | --- |
| `stat` | 获取路径对应文件的属性；路径是链接时，得到源文件属性 |
| `lstat` | 获取路径本身的属性；路径是链接时，得到链接文件自身属性 |
| `fstat` | 使用已打开文件的文件描述符获取属性 |

## struct stat

```c
struct stat
{
    dev_t st_dev;
    ino_t st_ino;
    mode_t st_mode;
    nlink_t st_nlink;
    uid_t st_uid;
    gid_t st_gid;
    dev_t st_rdev;
    off_t st_size;
    blksize_t st_blksize;
    blkcnt_t st_blocks;
    time_t st_atime;
    time_t st_mtime;
    time_t st_ctime;
};
```

重要字段：

| 字段 | 含义 |
| --- | --- |
| `st_ino` | 索引节点号 |
| `st_mode` | 文件类型和权限 |
| `st_nlink` | 硬链接数 |
| `st_uid` | 所有者用户 ID |
| `st_gid` | 组 ID |
| `st_size` | 文件大小，单位字节 |
| `st_atime` | 最后访问时间 |
| `st_mtime` | 最后修改时间 |
| `st_ctime` | 创建时间 |

## st_mode

- `st_mode` 是 32 位整数。
- 当前 Linux 只使用低 16 位。
- 高 4 位表示文件类型。
- 低 9 位表示 User、Group、Other 三组权限。

## 文件类型判断

```c
char Get_FileType(struct stat sb)
{
    char ch = 0;

    if (S_ISREG(sb.st_mode))
        ch = '-';
    if (S_ISDIR(sb.st_mode))
        ch = 'd';
    if (S_ISCHR(sb.st_mode))
        ch = 'c';
    if (S_ISBLK(sb.st_mode))
        ch = 'b';
    if (S_ISFIFO(sb.st_mode))
        ch = 'p';
    if (S_ISLNK(sb.st_mode))
        ch = 'l';
    if (S_ISSOCK(sb.st_mode))
        ch = 's';

    return ch;
}
```

## 权限判断

```c
static char buf[10] = "---------";

if (sb.st_mode & S_IRUSR)
    buf[0] = 'r';
if (sb.st_mode & S_IWUSR)
    buf[1] = 'w';
if (sb.st_mode & S_IXUSR)
    buf[2] = 'x';
```

其他两组权限分别使用：

```text
S_IRGRP S_IWGRP S_IXGRP
S_IROTH S_IWOTH S_IXOTH
```

## 模拟 ls -li

| 选项 | 含义 |
| --- | --- |
| `-l` | 显示文件详细信息 |
| `-i` | 显示文件 inode |

程序需要输出：

1. inode。
2. 文件类型。
3. 九位权限。
4. 硬链接数。
5. 文件大小。
6. 最后修改时间。
7. 文件名。

完整流程：

```c
DIR *dir = opendir(path);
struct dirent *file = NULL;
struct stat buf = {0};

while ((file = readdir(dir)) != NULL)
{
    if (file->d_name[0] == '.')
        continue;

    lstat(file->d_name, &buf);

    printf("%ld %c", buf.st_ino, Get_FileType(buf));
    Get_FileMode(buf);
    printf(" %2ld %5ld ", buf.st_nlink, buf.st_size);
    Time_Change(buf);
    printf("%s\n", file->d_name);
}

closedir(dir);
```

权限位也可以循环输出：

```c
char flags[3] = {'r', 'w', 'x'};

for (int i = 0; i < 9; i++)
{
    printf("%c", ((sb.st_mode & 0400) >> i) ? flags[i % 3] : '-');
}
```
