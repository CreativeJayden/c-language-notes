## 目录操作流程

```text
打开目录 -> 读取目录 -> 关闭目录
```

主要函数：

```text
opendir closedir readdir
mkdir rmdir chdir chmod getcwd
```

## opendir

```c
DIR *opendir(const char *name);
```

头文件：

```c
#include <sys/types.h>
#include <dirent.h>
```

- 成功：返回目录流指针。
- 失败：返回 `NULL`。

## closedir

```c
int closedir(DIR *dirp);
```

- 成功返回 `0`。
- 失败返回 `-1`。

## readdir

```c
struct dirent *readdir(DIR *dirp);
```

每次读取目录中的一个目录项。

```c
struct dirent
{
    ino_t d_ino;
    unsigned char d_type;
    char d_name[256];
};
```

| 字段 | 含义 |
| --- | --- |
| `d_ino` | inode 节点号 |
| `d_type` | 文件类型 |
| `d_name` | 文件名 |

遍历目录：

```c
DIR *d = opendir(path);
struct dirent *e;

while ((e = readdir(d)) != NULL)
{
    printf("%s\n", e->d_name);
}

closedir(d);
```

## mkdir

```c
int mkdir(const char *pathname, mode_t mode);
```

创建目录，权限示例为 `0777`。

## rmdir

```c
int rmdir(const char *pathname);
```

只能删除空目录。

## chdir

```c
int chdir(const char *path);
```

切换到指定目录。

## chmod

```c
int chmod(const char *pathname, mode_t mode);
```

## getcwd

```c
char *getcwd(char *buf, size_t size);
```

获取当前绝对路径。
