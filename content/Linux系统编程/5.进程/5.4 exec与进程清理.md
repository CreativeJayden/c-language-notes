## exit 和 _exit

```c
void exit(int status);
```

头文件：

```c
#include <stdlib.h>
```

`exit` 会清理缓冲区。

```c
void _exit(int status);
```

头文件：

```c
#include <unistd.h>
```

`_exit` 不清理缓冲区。

用同一句 `printf("hello world\n");` 可以看出两者区别：

- 使用 `exit`：缓冲区被清理，内容会输出。
- 使用 `_exit`：缓冲区不清理，内容可能不输出。

## atexit

```c
int atexit(void (*function)(void));
```

功能：注册进程退出前执行的清理函数。

```c
void Func(void)
{
    /* 退出前执行的清理代码 */
}

int main(void)
{
    atexit(Func);
    return 0;
}
```

## vfork

```c
pid_t vfork(void);
```

特点：

1. 子进程先于父进程执行。
2. 子进程共享父进程的资源空间。

解决方式：

1. 子进程使用 `exit` 退出。
2. 子进程使用 `exec` 函数族。

## exec 函数族

功能：在当前进程中启动另一个程序，并覆盖原本的进程。

### execl

```c
int execl(const char *pathname, const char *arg, ...);
```

```c
execl("/usr/bin/ls", "ls", "-li", NULL);
```

### execlp

```c
int execlp(const char *file, const char *arg, ...);
```

```c
execlp("ls", "ls", "-li", NULL);
```

最后一个参数必须是 `NULL`。

> `exec` 的常见描述是“成功启动新程序，失败返回 `-1`”。成功后原进程已经被覆盖，原程序不会继续向下执行，因此不要依赖 `exec` 之后的返回值。

## system

```c
int system(const char *command);
```

```c
system("ls -li");
```

## 自动下一首

父进程先创建子进程调用 `exec` 播放当前歌曲，再用 `waitpid` 等待子进程结束。子进程结束后，父进程切换到下一首歌并再次创建子进程：

```c
while (1)
{
    pid_t pid = fork();

    if (pid == 0)
    {
        execlp("mpg123", "mpg123", songs[index], NULL);
        perror("execlp");
        exit(0);
    }
    else if (pid > 0)
    {
        waitpid(pid, NULL, 0);
        index++;
    }
}
```
