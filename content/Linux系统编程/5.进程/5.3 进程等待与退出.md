## 特殊进程

- `0` 号进程：引导操作系统启动的进程。
- `1` 号进程：祖先进程。

孤儿进程：

```text
父进程先结束，子进程被祖先进程收养。
```

僵尸进程：

```text
子进程先结束，父进程没有清理子进程，子进程变成僵尸进程。
```

## wait

```c
pid_t wait(int *wstatus);
```

头文件：

```c
#include <sys/types.h>
#include <sys/wait.h>
```

功能：阻塞等待子进程结束，并做清理工作。

```c
wait(NULL);
```

## waitpid

```c
pid_t waitpid(pid_t pid, int *wstatus, int options);
```

| 参数 | 含义 |
| --- | --- |
| `pid = -1` | 等待任意子进程 |
| `pid = 指定进程号` | 等待指定子进程 |
| `options = 0` | 阻塞等待 |
| `options = WNOHANG` | 非阻塞等待 |

等价关系：

```c
wait(NULL);
waitpid(-1, NULL, 0);
```

## 父进程监测子进程

```c
while (1)
{
    pid_t pid = fork();

    if (pid == 0)
    {
        printf("i am son\n");
        sleep(5);
        exit(0);
    }
    else if (pid > 0)
    {
        int res = waitpid(-1, NULL, 0);
        if (res == pid)
        {
            printf("子进程结束，创建新的子进程\n");
        }
    }
    else
    {
        perror("fork");
        return -1;
    }
}
```
