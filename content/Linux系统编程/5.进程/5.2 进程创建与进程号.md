## 获取进程号

```c
pid_t getpid(void);
pid_t getppid(void);
```

头文件：

```c
#include <sys/types.h>
#include <unistd.h>
```

- `getpid`：获取当前进程号。
- `getppid`：获取父进程号。

## fork

```c
pid_t fork(void);
```

返回值：

| 所在进程 | 返回值 |
| --- | --- |
| 父进程 | 子进程的进程号 |
| 子进程 | `0` |
| 创建失败 | `-1` |

## fork 的三个特点

1. 父子进程的执行顺序不确定。
2. 子进程从 `fork` 调用点以下开始执行。
3. 子进程复制父进程的资源，父子进程各自拥有独立空间。

示例：

```c
int num = 100;
pid_t pid = fork();

if (pid == 0)
{
    num++;
    printf("son num=%d pid=%d ppid=%d\n",
           num, getpid(), getppid());
}
else if (pid > 0)
{
    printf("father num=%d pid=%d ppid=%d\n",
           num, getpid(), getppid());
}
else
{
    perror("fork");
}
```

## 连续 fork

```c
fork();
fork();
fork();
printf("hello world\n");
```

三次连续 `fork` 后进程总数从 `1` 变为 `8`，最后一行 `printf` 输出 8 次。
