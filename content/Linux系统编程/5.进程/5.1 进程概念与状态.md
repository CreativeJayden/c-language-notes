## 程序与进程

- 代码是文本文件或字符文件，存放在磁盘空间。
- 代码经过编译得到程序，程序存放在磁盘空间。
- 程序运行起来以后成为进程，进程位于内存。

## 查看进程

| 命令 | 侧重点 |
| --- | --- |
| `ps -ef` | 查看进程号 PID 和父进程号 PPID |
| `ps -aux` | 查看进程状态 |
| `top` | 动态查看进程 |

常见状态：

| 状态 | 含义 |
| --- | --- |
| `R` | 运行 |
| `S` | 休眠 |
| `Z` | 僵尸 |

## 进程的特点

- 动态性
- 并发性
- 独立性
- 异步性

## 进程的资源空间

C 程序运行时的五个内存区域：

```text
堆区、栈区、全局/静态存储区、常量区、代码段
```

## 进程状态

| 状态 | 含义 |
| --- | --- |
| 执行态 | 正在使用 CPU 运行 |
| 就绪态 | 已具备运行条件，等待 CPU 时间片 |
| 等待态 | 等待某个资源或事件完成 |

状态变化：

```text
就绪 --获得 CPU 时间片--> 执行
执行 --时间片用完--> 就绪
执行 --等待资源--> 等待
等待 --资源满足--> 就绪
```

## 创建和终止进程

创建进程：

- 运行可执行程序，例如 `./xxx`。
- 使用 `fork` 或 `vfork` 创建。

终止进程：

- `Ctrl + C`
- `Ctrl + \`
- `kill -9 进程号`
