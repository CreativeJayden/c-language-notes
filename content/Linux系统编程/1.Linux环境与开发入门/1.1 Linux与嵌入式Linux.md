## 嵌入式 Linux

嵌入式是把芯片嵌入产品，让产品具备计算和控制能力。硬件是基础，软件决定硬件能够完成什么功能。

嵌入式方向分为：

- 嵌入式硬件：焊接、PCB、硬件选型和调试。
- 嵌入式软件：需要了解电子元器件，并会使用万用表、示波器和逻辑分析仪等工具。

嵌入式软件有两条主要路线：

| 路线 | 特点 | 典型场景 |
| --- | --- | --- |
| `MCU + RTOS` | 使用单片机、实时操作系统 | FreeRTOS、UCOS、RTThread |
| `SOC + Linux` | 使用性能更高的芯片和 Linux | 摄像头、广告机、AI 边缘盒子、网络机顶盒 |

功能较多、性能要求较高时，通常采用 `SOC + Linux`。

## Linux 操作系统

操作系统负责管理和控制计算机的软硬件资源，是人和硬件之间的中间层。

常见操作系统包括 Windows、Linux、鸿蒙、安卓、macOS。

常见的 Linux 发行版包括 Ubuntu、CentOS、RedHat，它们都基于 Linux 内核。课程使用 **Ubuntu 20.04 桌面版**。

## 为什么使用 Linux 学习 C

后续课程需要学习 Linux 系统编程和 Linux 驱动开发，因此直接在 Linux 环境中学习 C 语言。这样可以同时熟悉：

- C 代码的编辑、编译和执行。
- Linux 终端和常用命令。
- Linux 提供的系统调用和开发工具。

## Linux 安装方式

Linux 常见的安装方式有三种：

1. 舍弃 Windows，只安装 Linux。
2. 安装 Windows 和 Linux 双系统，开机时选择系统。
3. 使用虚拟机模拟计算机硬件，在虚拟机中安装 Linux。

课程采用虚拟机方式，使用的虚拟机软件是 VMware Workstation。
