## 主函数传参

```c
int main(int argc, char *argv[])
{
    return 0;
}
```

| 参数 | 含义 |
| --- | --- |
| `argc` | 参数个数 |
| `argv[]` | 指针数组，也叫字符串数组，保存每个参数的内容 |

运行：

```bash
./a.out aaaa hehe heilei
```

对应的参数：

```text
argc = 4
argv[0] = ./a.out
argv[1] = aaaa
argv[2] = hehe
argv[3] = heilei
```

## atoi

`atoi` 用于把字符串转换为整数：

```c
#include <stdlib.h>

int atoi(const char *nptr);
```

```c
int num = atoi("88");
```

## 四则运算程序设计

```text
输入：./a.out 8 + 9
输出：8 + 9 = 17
```

参数拆解：

| 位置 | 值 | 含义 |
| --- | --- | --- |
| `argv[0]` | `./a.out` | 程序名 |
| `argv[1]` | `"8"` | 第一个操作数，字符串 |
| `argv[2]` | `"+"` | 运算符，字符串 |
| `argv[3]` | `"9"` | 第二个操作数，字符串 |
| `argc` | `4` | 参数个数 |

操作数是字符串，必须用 `atoi` 转成整数：

```c
int a = atoi(argv[1]);
int b = atoi(argv[3]);
```

运算符只需要取 `argv[2]` 的第一个字符：

```c
char op = *argv[2];
```

## 完整主函数框架

```c
#include "main.h"

int main(int argc, char *argv[])
{
    int a, b, i;
    FUNC p[] = {Add, Sub, Mul, Div};

    if (argc != 4)
    {
        printf("输入有误，请按 a+b 格式输入\n");
        return -1;
    }

    a = atoi(argv[1]);
    b = atoi(argv[3]);

    switch (*argv[2])
    {
    case '+': i = 0; break;
    case '-': i = 1; break;
    case '*': i = 2; break;
    case '/': i = 3; break;
    default:
        printf("输入有误\n");
        return 0;
    }

    printf("%d %c %d = %d\n", a, *argv[2], b, p[i](a, b));
    return 0;
}
```

`main.h`：

```c
#ifndef _MAIN_H_
#define _MAIN_H_

#include <stdio.h>
#include <stdlib.h>
#include "add.h"
#include "del.h"
#include "mul.h"
#include "div.h"

typedef int (*FUNC)(int, int);

#endif
```

## 模块化结构

```text
add.h / add.c
del.h / del.c
mul.h / mul.c
div.h / div.c
main.h / main.c
```

其中 `Add(2, 3)` 等价于 `p[0](2, 3)`。

## 除法注意点

除法运算要判断除数是否为 `0`，否则会出现运行时错误。

## chmod 命令

| 字符 | 权限 | 数字 |
| --- | --- | --- |
| `r` | 读 | `4` |
| `w` | 写 | `2` |
| `x` | 执行 | `1` |

```bash
chmod 0777 文件名    # rwxrwxrwx
chmod 0755 文件名    # rwxr-xr-x
chmod 0644 文件名    # rw-r--r--
chmod u-rx 文件名
chmod o+w 文件名
```
