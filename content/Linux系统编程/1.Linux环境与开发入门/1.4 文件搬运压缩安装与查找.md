title: 文件搬运压缩安装与查找
---

## cp：复制

```bash
cp 源文件 目标文件
cp 源文件 目标路径
cp 源目录 目标路径 -r
```

## mv：移动或改名

```bash
mv 源文件 目标路径
mv 原文件名 新文件名
```

剪切目录不需要加 `-r`。

## zip 和 unzip

```bash
zip 压缩包.zip 要压缩的内容
zip 压缩包.zip 目录 -r
unzip 压缩包.zip
```

## tar

```bash
tar -cvf 压缩包.tar 要压缩的内容
tar -xvf 压缩包.tar
tar -xvf 压缩包.tar -C 解压位置
```

## 软件安装

```bash
sudo apt install 软件包名
sudo apt update
sudo apt remove 软件名
sudo dpkg -i 安装包.deb
sudo dpkg -r 软件名
```

## 网络管理

```bash
ping 网址或IP地址
ifconfig
```

按 `Ctrl + C` 结束 `ping`。

## find：查找文件

```bash
sudo find / -name ls
find china -type d
```

`-name` 按名字匹配，`-type` 按文件类型匹配。

## 重定向

`>` 表示写入；`>>` 表示追加写入：

```bash
cat 1.c > 2.c
cat 1.c >> 2.c
echo 字符串 > 1.c
echo 字符串 >> 1.c
```

## 用户管理补充

```bash
sudo adduser 用户名
sudo userdel -r 用户名
```

## 硬链接和软链接

```bash
ln 源文件 链接后的文件
ln -s 源文件 链接后的文件
```

| 项目 | 硬链接 | 软链接 |
| --- | --- | --- |
| inode | 相同 | 不同 |
| 文件类型 | 与源文件一致 | 链接文件 `l` |
| 删除源文件 | 链接仍可用 | 链接失效 |
