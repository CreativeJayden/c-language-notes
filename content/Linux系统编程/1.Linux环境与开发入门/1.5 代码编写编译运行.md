## 编写第一个程序

```bash
gedit 1.c
```

```c
#include <stdio.h>

int main()
{
    printf("hello world!\n");
    return 0;
}
```

## 编译和运行

```bash
gcc 1.c
./a.out
gcc 1.c -o 111
./111
```

第一次使用 `gcc` 时，如果系统提示找不到命令，需要先安装：

```bash
sudo apt install gcc
```

## 常见错误

- 代码中的标点必须在英文输入状态下输入。
- 括号和引号要成对出现。
- 链接错误 `undefined reference to main` 表示 `main` 名称写错或不存在。
