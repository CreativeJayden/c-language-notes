## 虚拟机环境

课程使用 VMware Workstation 创建虚拟机，并在虚拟机中安装 Ubuntu 20.04 桌面版。

为了让 Windows 和 Linux 虚拟机之间可以复制、粘贴，需要安装 VMware 工具：

```bash
sudo apt update
sudo apt install open-vm-tools
sudo apt install open-vm-tools-desktop
```

安装完成后重启虚拟机。

## 打开和关闭终端

终端是输入命令的地方。输入命令并按下回车后，系统会执行对应操作。

打开终端：

- 在空白位置单击右键，选择“在终端打开”。
- `Ctrl + Alt + T`。
- 已经打开一个终端时，按 `Ctrl + Shift + T` 新建终端。

关闭终端：

- 点击窗口右上角的关闭按钮。
- `Ctrl + Shift + W`。

常用终端快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 放大终端 | `Ctrl + Shift + =` |
| 缩小终端 | `Ctrl + -` |
| 复制 | `Ctrl + Shift + C` |
| 粘贴 | `Ctrl + Shift + V` |
| 中英文切换 | 配置智能拼音后按 `Shift` |

## 终端提示符

终端提示符通常形如：

```text
用户名@计算机名:当前路径$
```

- `$`：普通用户。
- `#`：管理员用户。
- `~`：当前用户的家目录。

## 家目录

普通用户的家目录通常位于：

```text
/home/用户名
```

例如 `/home/wqh` 等价于 `~`。日常操作大多在家目录中进行。
