## Linux 目录结构

Windows 把存储分成 C 盘、D 盘、E 盘；Linux 没有盘符，所有内容都从根目录 `/` 开始。

路径分为：

- 绝对路径：从根目录 `/` 开始。
- 相对路径：从当前路径开始。

```bash
pwd
```

## 学习命令的方法

```bash
man 命令
命令 --help
```

命令的基本格式是：

```text
命令 [选项] [参数]
```

## ls：查看目录内容

```bash
ls 路径
ls -a
ls -l
```

- 不写路径时，查看当前目录。
- `-a`：包含以 `.` 开头的隐藏文件。
- `-l`：显示详细信息。

Linux 下一切皆文件。文件类型标识如下：

| 标识 | 文件类型 |
| --- | --- |
| `b` | 块设备文件 |
| `c` | 字符设备文件 |
| `d` | 目录文件 |
| `p` | 管道文件 |
| `s` | 套接字文件 |
| `l` | 链接文件 |
| `-` | 普通文件 |

`ls -l` 的三组 `rwx` 分别表示创建者、同组用户、其他用户的权限。

## cd：切换目录

| 路径 | 含义 |
| --- | --- |
| `/` | 根目录 |
| `~` | 家目录 |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `-` | 上一次所在目录 |

## mkdir、touch、gedit、cat、rm

```bash
mkdir 目录
mkdir -p 目录1/目录2/目录3
touch 文件名
gedit 文件名
cat 文件名
rm 文件
rm 目录 -r
rmdir 空目录
```

## 通配符

| 通配符 | 作用 |
| --- | --- |
| `*` | 匹配任意多个字符 |
| `?` | 匹配一个字符 |
| `[]` | 匹配指定范围 |

## 用户与权限

```bash
su 用户名
passwd 用户名
sudo 命令
```

- `su` 切换用户。
- `passwd` 修改或设置用户密码。
- 普通用户权限不足时，可以在命令前加 `sudo`。

`chmod` 的详细用法见 [[1.6 主函数传参]]。

## 其他常用操作

```bash
clear
history
```

- `clear`：清屏。
- `history`：查看历史命令。
- `Tab`：自动补全。
