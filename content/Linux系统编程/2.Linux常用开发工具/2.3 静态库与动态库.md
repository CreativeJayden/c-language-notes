---

## 库

库是已经编译好的、可复用的二进制代码集合，用于提供函数、变量或类的实现。使用库可以避免重复编写相同功能，也方便保护源码和移植。

| 类型 | 文件后缀 |
| --- | --- |
| 静态库 | `.a` |
| 动态库 | `.so` |

## 制作静态库

```bash
gcc -c fun.c -o fun.o
ar -rc lib库名.a fun.o
gcc main.c -o main -l库名 -L库的路径
```

## 制作动态库

```bash
gcc -fpic -c fun.c -o fun.o
gcc -fpic -shared fun.o -o lib库名.so
sudo mv lib库名.so /usr/lib
gcc main.c -o main -l库名 -L库的路径
```

## 静态库与动态库的区别

| 类型 | 编译和运行特点 | 概括 |
| --- | --- | --- |
| 静态库 | 链接时把库代码复制到可执行程序中；删除静态库后程序仍可运行 | 以空间换时间 |
| 动态库 | 运行时再加载；删除动态库后程序不能运行 | 以时间换空间 |
