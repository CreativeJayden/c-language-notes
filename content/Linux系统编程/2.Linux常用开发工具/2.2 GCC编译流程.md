---
title: GCC编译流程
---

GCC 编译 C 语言，G++ 编译 C++。

假设当前文件是 `main.c`，完整流程分为四步：

## 1. 预处理

处理以 `#` 开头的预处理指令。

```bash
gcc -E main.c -o main.i
```

## 2. 编译

把预处理后的代码转换为汇编代码。

```bash
gcc -S main.i -o main.s
```

## 3. 汇编

把汇编代码转换为二进制目标文件。

```bash
as main.s -o main.o
```

## 4. 链接

把目标文件和库链接为可执行程序。

```bash
gcc main.o -o main
```

## 常用编译参数

| 参数 | 作用 |
| --- | --- |
| `-o` | 重命名输出文件 |
| `-c` | 只编译不链接 |
| `-I` | 指定头文件搜索路径 |
| `-l` | 指定库名，参数是小写字母 `l` |
| `-L` | 指定库文件搜索路径 |
| `-g` | 生成带调试信息的可执行程序 |

`-c` 等价于完成预处理、编译和汇编，但不进行链接：

```bash
gcc -c main.c -o main.o
```
