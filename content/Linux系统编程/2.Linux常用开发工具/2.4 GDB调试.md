## 调试思路

```text
测试 -> 固化 -> 定位 -> 修改 -> 验证
```

常见的辅助方法是使用 `printf` 输出变量和关键位置，再配合注释缩小问题范围。

Linux 提供的调试工具是 GDB。

## 生成调试信息

编译时必须加入 `-g`：

```bash
gcc -g main.c -o main
gdb ./main
gdb -args ./a.out 8 + 9
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `r` / `run` | 开始运行 |
| `q` / `quit` | 退出 |
| `l` / `list` | 查看代码 |
| `c` / `cont` | 继续运行 |
| `b 行号` | 设置断点 |
| `info b` | 查看断点 |
| `enable 编号` | 启用断点 |
| `disable 编号` | 禁用断点 |
| `delete 编号` | 删除断点 |
| `clear 行号` | 清除指定行的断点 |
| `p 变量名` | 打印变量 |

## 单步调试

| 命令 | 作用 |
| --- | --- |
| `start` | 开始运行并停在主函数 |
| `n` / `next` | 执行下一步，不进入子函数 |
| `s` / `step` | 执行下一步，进入子函数 |
| `finish` | 跳出当前子函数 |

常用的单步策略：

```text
start 开始运行，用 n 把控全局，选择性地使用 s，实时使用 p 查看变量。
```
