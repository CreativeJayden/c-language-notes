## 为什么要学习 Vim

图形界面中可以使用 gedit、VS Code 等编辑器。但在纯命令行界面中无法使用图形编辑器，只能使用基于终端的 Vim。

```bash
sudo apt install vim
```

个人配置一般通过 `.vimrc` 管理，课件中的做法是把配置文件复制到虚拟机家目录。

## 打开文件

```bash
vim 文件名
```

- 文件存在：打开文件。
- 文件不存在：创建并打开文件。

## 四种模式

| 模式 | 作用 |
| --- | --- |
| 命令模式 | 复制、删除、撤销等 |
| 插入模式 | 输入和修改文本 |
| 底行模式 | 保存、退出、查找和替换 |
| 可视模式 | 选中并操作一段内容 |

其他模式下按 `Esc` 返回命令模式。

## 命令模式

| 命令 | 作用 |
| --- | --- |
| `yy` | 复制当前行 |
| `nyy` | 复制当前行及下面 `n-1` 行 |
| `yw` | 复制一个单词 |
| `nyw` | 复制当前单词及后面 `n-1` 个单词 |
| `p` | 粘贴 |
| `ndd` | 删除当前行及下面 `n-1` 行 |
| `ndw` | 删除当前单词及后面 `n-1` 个单词 |
| `nx` | 删除当前字符及后面 `n-1` 个字符 |
| `nX` | 删除光标前的 `n` 个字符 |
| `u` | 撤销 |
| `Ctrl + R` | 反撤销 |

## 插入模式

| 按键 | 插入位置 |
| --- | --- |
| `I` | 当前行行首 |
| `A` | 当前行行尾 |
| `O` | 当前行上方新建一行 |
| `i` | 光标当前位置 |
| `a` | 光标后一个位置 |
| `o` | 当前行下方新建一行 |

## 底行模式

```text
:wq
:w
:q!
/字符串
?字符串
:noh
:%s/源字符串/目标字符串/g
```

- `wq`：保存并退出。
- `w`：保存。
- `q!`：强制退出。
- `/` 和 `?` 用于查找。
- `noh` 取消高亮。
- `%s/.../.../g` 进行全文替换。

## 可视模式

在命令模式按 `v` 进入可视模式。

| 按键 | 作用 |
| --- | --- |
| `y` | 复制 |
| `d` | 删除 |
| `p` | 粘贴 |
| `x` | 剪切 |

## 非正常关闭

Vim 非正常关闭时，会在文件所在目录生成 `.swp` 交换文件。解决方法是删除该 `.swp` 文件。
