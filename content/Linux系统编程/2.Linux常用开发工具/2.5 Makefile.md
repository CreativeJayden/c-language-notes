## Makefile 的作用

Makefile 是工程管理工具。一个工程可能包含多个目录、多个源文件和多个模块，Makefile 用规则规定：

- 哪些文件需要先编译。
- 哪些文件需要后编译。
- 哪些文件需要重新编译。
- 如何链接生成最终目标。

```bash
sudo apt install make
```

## 特点

- 自动化编译：在 Makefile 所在目录执行 `make`。
- 编译效率高：第一次编译后，后续只重新编译发生变化的部分。

默认文件名是 `Makefile` 或 `makefile`。如果使用其他名称，需要加 `-f`：

```bash
make -f 文件名
```

## 基本规则

```make
目标:依赖
	命令
```

命令前的缩进必须是 **TAB**。

没有依赖的目标称为伪目标：

```make
clean:
	rm -f *.o main
```

执行 `make` 默认运行第一个目标，执行指定目标：

```bash
make clean
```

如果当前目录存在名为 `clean` 的文件，需要声明伪目标：

```make
.PHONY:clean
```

## 变量

```make
CC=gcc
CFLAGS=-g
$(CC) $(CFLAGS) main.c -o main
```

| 写法 | 含义 |
| --- | --- |
| `=` | 普通赋值 |
| `?=` | 前面未赋值时才赋值 |
| `:=` | 立即赋值 |
| `+=` | 在原有值后追加 |

## 特殊变量

| 变量 | 含义 |
| --- | --- |
| `$@` | 当前目标 |
| `$^` | 所有依赖 |
| `$<` | 第一个依赖 |

模式规则：

```make
%.o:%.c
	$(CC) -c $< -o $@
```

## 常用函数

| 函数 | 作用 |
| --- | --- |
| `wildcard` | 查找指定文件 |
| `notdir` | 去掉路径，只保留文件名 |
| `patsubst` | 按模式替换字符串 |

示例：

```make
CFILES=$(wildcard ./src/*.c)
NOPATH=$(notdir $(CFILES))
OFILES=$(patsubst %.c,%.o,$(NOPATH))
```

工程版 Makefile 使用 `src/`、`include/`、`lib/`、`output/` 等目录，并通过 `CFLAGS=-I ./include` 指定头文件路径。
