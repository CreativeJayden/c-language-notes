## 文件的介绍

文件是数据存储的载体。文件可以分为文本文件和二进制文件。

文件操作的流程：

1. 打开文件。
2. 对文件进行读写。
3. 关闭文件。


## fopen 函数

打开文件。

```c
FILE *fopen(const char *pathname, const char *mode);
```

- 头文件：`<stdio.h>`
- `pathname`：带路径的文件名
- `mode`：打开文件的模式
- 成功：返回文件流指针
- 失败：返回 `NULL`

```c
FILE *fp = fopen("1.txt", "w+");
```

常见模式：

```text
r  只能打开存在的文件
w  文件不存在时新建，存在时清空
a  文件不存在时新建，存在时在末尾追加
r+ 读写，文件必须存在
w+ 读写，文件不存在时新建，存在时清空
a+ 读写，文件不存在时新建，存在时追加
```

只需要使用一个指针变量保存文件，后续通过该变量操作文件。

```c
#include <stdio.h>

int main()
{
    FILE *fp = NULL;

    fp = fopen("2.txt", "a");
    if (fp == NULL)
    {
        printf("文件打开失败!\n");
    }
    else
    {
        printf("文件打开成功!\n");
    }

    return 0;
}
```


## fclose 函数

关闭文件。

```c
int fclose(FILE *stream);
```

- 头文件：`<stdio.h>`
- `stream`：文件流指针，即 `fopen` 的返回值
- 成功：返回 `0`
- 失败：返回 `EOF`

```c
int res = fclose(fp);
if (res == 0)
{
    printf("文件关闭成功!\n");
}
else
{
    printf("文件关闭失败!\n");
}
```


## 单字符读写

### fputc

将字符写入文件流。

```c
int fputc(int character, FILE *stream);
```

- 成功：返回被写入的字符
- 失败：返回 `EOF`

### fgetc

从文件流读取一个字符。

```c
int fgetc(FILE *stream);
```

- 成功：返回读取到的字符
- 失败或到达文件末尾：返回 `EOF`


## 字符串读写

### fputs

将字符串写入文件流。

```c
int fputs(const char *str, FILE *stream);
```

- `str`：要写入的字符串
- `stream`：文件流指针
- 成功：返回非负值
- 失败：返回 `EOF`

### fgets

从文件流读取一行，存入 `str`。

```c
char *fgets(char *str, int n, FILE *stream);
```

- `str`：读取到的内容存放的位置
- `n`：读取大小
- `stream`：文件流指针
- 成功：返回读取到的字符串
- 失败：返回 `NULL`

### 标准流

程序运行起来时，默认打开三个文件流指针：

- `stdin`：标准输入，对应键盘。
- `stdout`：标准输出，对应屏幕。
- `stderr`：标准错误，对应屏幕。

课件中的等价关系：

```c
puts(buf);
fputs(buf, stdout);

gets(buf);
fgets(buf, sizeof(buf), stdin);
```

## 注意点

- `fgetc` 的返回值应保存为 `int`，这样才能同时表示普通字节值和 `EOF`。
- `feof` 只有在一次读取尝试已经到达文件末尾后才会置位，不能用它提前判断“下一条记录是否存在”。
- 逐行读取并使用 `sscanf` 解析字段时，要检查字段返回个数和字符串宽度。相关写法见 [[9.3 文件定位与 CSV 操作]]。
