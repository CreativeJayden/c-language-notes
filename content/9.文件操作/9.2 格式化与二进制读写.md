## 格式化读写

### fprintf

格式化写入文件流。

```c
int fprintf(FILE *stream, const char *format, ...);
```

- 成功：返回写入的字符总数
- 失败：返回负数
- `format` 和 `printf` 的用法一样

```c
printf("%s", buf);
fprintf(stdout, "%s", buf);

fprintf(fp, "%s", buf);
```

### fscanf

格式化读取。

```c
int fscanf(FILE *stream, const char *format, ...);
```

- 成功：返回成功匹配和赋值的个数
- 到达文件末尾或发生读错误：返回 `EOF`
- `format` 和 `scanf` 的用法一样

```c
char buf[100];
int num;

scanf("哈哈哈%s%d", buf, &num);
fscanf(fp, "", buf, &num);
```

两份课件对 `fscanf` 返回值的表述不同：

- 完整版课件写到返回成功匹配和赋值的个数，文件末尾或读错误返回 `EOF`。

## 二进制读写

### fwrite

把 `ptr` 中的内容按二进制写入文件流。

```c
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

- `ptr`：要写入内容的首地址
- `size`：一次写入数据块的大小
- `nmemb`：写入多少个 `size` 大小的数据
- `stream`：文件流指针
- 成功：返回实际写入的元素个数
- 返回值与 `nmemb` 不同：发生错误

```c
STU student = {"李四", 123, 66};
fwrite(&student, sizeof(STU), 1, fp);
```

### fread

从文件流读取二进制内容到 `ptr`。

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

- `ptr`：读取内容存放的位置
- `size`：读取的数据块大小
- `nmemb`：读取多少个数据块
- `stream`：文件流指针
- 成功：返回实际读取的元素个数
- 返回值与 `nmemb` 不同：可能发生错误或到达文件末尾

```c
STU student = {0};
fread(&student, sizeof(STU), 1, fp);
```

二进制读写示例中使用结构体数组：

```c
struct STUDENT
{
    unsigned int id;
    char name[32];
};

struct STUDENT student[3] =
{
    {1001, "Jack"},
    {1002, "Tom"},
    {1003, "rose"}
};
```

## 注意点

- `fscanf` 返回成功匹配并赋值的字段数；字段不完整时不能只判断是否等于 `EOF`。
- `fread` 返回实际读到的完整元素个数。返回 `0` 时还要结合请求长度、`feof` 和 `ferror` 判断是到达末尾还是发生错误。
- 直接按 `sizeof(struct STUDENT)` 读写会把填充字节、本机字节序和 ABI 布局一起写入文件，不适合作为稳定的跨平台格式。
