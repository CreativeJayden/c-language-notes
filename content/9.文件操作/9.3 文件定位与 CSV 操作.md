## 文件定位

### fseek

调整文件光标位置。

```c
int fseek(FILE *stream, long int offset, int whence);
```

- `stream`：文件流指针
- `offset`：偏移量，负数向文件开头偏，正数向文件末尾偏
- `SEEK_SET`：文件开头
- `SEEK_CUR`：当前位置
- `SEEK_END`：文件末尾
- 成功：返回 0
- 失败：返回非零值

```c
fseek(fp, 0, SEEK_SET);
fseek(fp, sizeof(struct STUDENT), SEEK_CUR);
fseek(fp, -sizeof(struct STUDENT) * 2, SEEK_CUR);
```

### ftell

返回光标此时距离文件开头的位置。

```c
long int ftell(FILE *stream);
```

- 成功：返回光标距离文件开头的位置
- 失败：返回 `-1`

### rewind

将光标偏移到文件开头。

```c
void rewind(FILE *stream);
```

`rewind(fp)` 等价于 `fseek(fp, 0, SEEK_SET)`。

### feof

判断文件是否到达末尾。

```c
int feof(FILE *stream);
```

- 到达文件末尾：返回非 0
- 未到达文件末尾：返回 0


## 文件操作的组合示例

写入多个结构体后，文件光标在文件末尾。要重新读取第一个学生信息，需要先回到文件开头：

```c
rewind(fp);
fread(&read_stu, sizeof(struct STUDENT), 1, fp);
```

读取第 2 个学生信息时，可以从当前位置跳过第 1 个结构体：

```c
rewind(fp);
fseek(fp, sizeof(struct STUDENT), SEEK_CUR);
fread(&read_stu, sizeof(struct STUDENT), 1, fp);
```


## CSV 文件操作

CSV 文件以表格形式存储数据。

```c
for (int i = 0; i < 3; i++)
{
    fprintf(fp, "%d,%s\n", student[i].id, student[i].name);
}
```

```c
fseek(fp, 0, SEEK_SET);
fscanf(fp, "%d,%s\n", &read_stu.id, read_stu.name);
```

把学生管理系统的信息存储到 CSV 文件中：

1. 系统关闭时，把学生信息存入 CSV 文件。
2. 系统启动后，立刻从 CSV 文件读取学生信息。

课件提出用 `fread` 或 `fscanf` 的返回值判断是否读完：`fread` 返回 `0` 代表读取失败；旧版课件对 `fscanf` 写到返回值 `0` 代表读取失败。读取文件时使用 `a` 或 `r` 模式，退出系统保存时使用 `w` 模式。

本知识库中实际讨论的 `fgets + sscanf` 读取方式见本页“注意点”，20 条学生信息示例见 [学生信息 CSV](../示例代码/students.csv)。


## 学生信息读取示例

课件要求学生信息能够保存到文件，并在系统启动后从文件读取。对话中进一步讨论了使用 `fgets` 逐行读取，再用 `sscanf` 解析字段的方法。

对应代码：

```c
while (fgets(line, sizeof line, fp) != NULL)
{
    int fields = sscanf(
        line,
        "%d,%31[^,],%7[^,],%d,%15[^,],%lf",
        &student->id,
        student->name,
        student->gender,
        &student->age,
        student->tel,
        &student->score
    );
}
```

完整程序见 [student_records.c](../示例代码/student_records.c)。

## 注意点

### 用 fgets 和 sscanf 读取逗号分隔记录

实际讨论的数据模板如下：

```text
1001,李白,男,11,12234556788,89.0
```

直接使用下面的写法不适合解析逗号分隔字段，因为 `%s` 读取非空白字符，不会在逗号处主动停止：

```c
fscanf(fp, "%d,%14s,%4s,%d,%12s,%f",
        &new->stu.id,
        new->stu.name,
        new->stu.gender,
        &new->stu.age,
        new->stu.tel,
        &new->stu.score);
```

改为先用 `fgets` 读取整行，再用 `sscanf` 解析六个字段：

```c
char line[256];
Student *new = malloc(sizeof *new);

if (new == NULL) {
    return false;
}

if (fgets(line, sizeof line, fp) == NULL) {
    free(new);
    return false;
}

int fields = sscanf(line,
                    "%d,%31[^,],%7[^,],%d,%15[^,],%lf",
                    &new->stu.id,
                    new->stu.name,
                    new->stu.gender,
                    &new->stu.age,
                    new->stu.tel,
                    &new->stu.score);

if (fields != 6) {
    free(new);
    return false;
}
```

- `%31[^,]` 表示最多读取 31 个非逗号字符，要为结尾的 `'\0'` 留出一个字节。
- `%7[^,]` 和 `%15[^,]` 分别要匹配 `gender[8]` 与 `tel[16]` 的容量。
- 字符串宽度限制按字节计算；包含汉字时，要考虑 UTF-8 汉字占用的多个字节，不能把字符数直接当作缓冲区字节数。
- `sscanf` 的返回值不是 `6` 时，应拒绝这一行；如果已经为节点分配了内存，还要及时释放，避免内存泄漏。
- 20 条学生信息保存在 [students.csv](../示例代码/students.csv)，完整读取程序见 [student_records.c](../示例代码/student_records.c)。
