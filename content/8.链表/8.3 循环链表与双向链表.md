## 循环链表和双向链表

### 循环链表

尾节点的指针域中存放头节点的地址。

循环链表没有自然的 `NULL` 终点，遍历时必须明确起点和停止条件：

```c
tmp = head;
do
{
    /* 输出 tmp 指向的信息 */
    tmp = tmp->next;
} while (tmp != head);
```

### 双向链表

- 单向链表：节点中只有一个指针域，存放下一个节点的地址。
- 双向链表：节点中有两个指针域，一个存放上一个节点的地址，另一个存放下一个节点的地址。

课件中的双向链表节点定义：

```c
typedef struct node
{
    STU student;
    struct node *front;
    struct node *next;
} NODE;
```

### 双向链表尾插

找到尾节点后，把新节点接到尾节点之后，并同时维护 `front` 和 `next`：

```c
tmp = head;
while (tmp->next != NULL)
{
    tmp = tmp->next;
}

new->front = tmp;
new->next = NULL;
tmp->next = new;
```

### 双向链表删除

让前驱和后继相互连接，再释放目标节点：

```c
tmp->front->next = tmp->next;
if (tmp->next != NULL)
{
    tmp->next->front = tmp->front;
}
free(tmp);
```

如果删除的是尾节点，`tmp->next` 为 `NULL`，不需要再修改后继节点的 `front`。

## 注意点

- 循环链表遍历时要防止条件写成 `tmp != NULL`，否则可能无法按预期结束。
- 双向链表插入或删除后，要同时检查正向和反向连接是否一致。
