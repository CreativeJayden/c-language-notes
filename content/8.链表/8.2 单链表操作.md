## 单链表实现增删改查

单链表包括增加、删除、修改、查询、遍历、排序和插入。

头节点的数据域中不存放数据，作为哨兵节点。

排序使用冒泡排序：先求出总个数，只交换数据域，不交换指针域。

插入时找到要插入的学号，先建立新节点与后继节点的连接，再修改前驱节点的指针，即先连后断。

## 头插法

新节点插到头节点之后：

```c
new->next = head->next;
head->next = new;
```

顺序不能反过来，否则会丢失原第一个数据节点的地址。

## 尾插法

先用循环找到尾节点，再把新节点接到尾节点之后：

```c
NODE *tmp = head;
while (tmp->next != NULL)
{
    tmp = tmp->next;
}

tmp->next = new;
new->next = NULL;
```

## 遍历

头节点的数据域不存放数据，遍历从 `head->next` 开始：

```c
NODE *tmp = head->next;
while (tmp != NULL)
{
    /* 输出 tmp 指向的学生信息 */
    tmp = tmp->next;
}
```

## 删除节点

先记录前驱节点和要删除的节点，让前驱跳过目标节点，再释放目标节点：

```c
tmp1->next = tmp->next; // tmp1前驱节点，tmp删除节点
free(tmp);
```

也可以从 `head` 开始查找目标节点的前驱：

```c
tmp = head;
while (tmp->next != NULL)
{
    if (tmp->next->student.id == del_id)
    {
        NODE *p = tmp->next;
        tmp->next = p->next;
        free(p);
        break;
    }
    tmp = tmp->next;
}
```

## 在指定节点后插入

先让新节点连接原后继，再让当前节点指向新节点：

```c
new->next = tmp->next;
tmp->next = new;
```

## 排序

排序可以使用冒泡排序：先求出节点总数，只交换数据域，不交换指针域。

## 注意点

- 插入和删除都要遵循“先连接，后断开”，避免提前覆盖仍然需要的指针。
- 删除节点前要保存它的地址；只修改前驱的 `next` 而不保存目标节点，之后就无法正确 `free`。
