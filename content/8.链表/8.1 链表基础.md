## 数据结构

- 线性结构：数组、栈、队列、链表。
- 非线性结构：树、堆、图。

学生管理系统可以用结构体数组编写，数组在定义时长度要尽量大：

```c
STU student[50];
```

如果每个结构体占 40 字节，数组大小为 `40 * 50 = 2000` 字节，会一次开辟一块 2000 字节的连续空间。

这有两个问题：

1. 空间资源浪费，并且必须是连续空间。
2. 资源开销较大。

链表动态开辟空间，添加一个学生时开辟空间，删除一个学生时释放空间，可以利用碎片化的空间。


## 链表的组成

链表由节点组成。

- 头节点：链表中的第一个节点。
- 尾节点：最后一个节点，指针域为 `NULL`。
- 数据域：存放数据。
- 指针域：存放下一个节点的地址。


## 节点的定义

数据域放姓名、学号和成绩，指针域存放下一个节点的地址。

直接定义节点：

```c
struct node
{
    char name[20];
    int id;
    float score;
    struct node *next;
};
```

先定义数据域，再定义节点：

```c
typedef struct
{
    char name[20];
    int id;
    float score;
} STU;

typedef struct node
{
    STU student;        // 数据域
    struct node *next;  // 指针域
} NODE;
```


## 相关函数

### malloc

手动开辟空间，返回开辟空间的首地址。

```c
void *malloc(size_t size);
```

- 头文件：`<stdlib.h>`
- 参数 `size`：要开辟空间的大小
- 返回值：开辟空间的首地址

### free

释放空间。

```c
void free(void *ptr);
```

- 头文件：`<stdlib.h>`
- 参数 `ptr`：要释放空间的地址
- 返回值：无

### perror

打印错误信息。

```c
void perror(const char *s);
```

- 头文件：`<stdlib.h>`
- 参数 `s`：字符串，一般给最近的函数名
- 返回值：无

### memset

将某块内存区域设置成指定的值。

```c
void *memset(void *s, int c, size_t n);
```

- 头文件：`<string.h>`
- 参数 `s`：要设置的地址
- 参数 `c`：设置的值，一般给 0
- 参数 `n`：大小
- 返回值：设置区域的首地址
