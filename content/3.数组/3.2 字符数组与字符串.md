## 字符数组

```c
char buf[32];
```

- `buf` 的类型是 `char [32]`。
- `buf[0]` 的类型是 `char`。
- 数组大小是 32 字节。

字符数组可以使用字符串初始化：

```c
char buf[32] = {"hello world"};
char buf[32] = {'h', 'e', 'l', 'l', 'o', '\0'};
char buf[32] = "河南郑州";
char buf[32] = {0};
char buf[32] = "\0";
```

字符串以 `'\0'` 结束。

### 输入和输出

```c
char buf[32] = "\0";
scanf("%s", buf);
printf("buf:%s\n", buf);
```

- `%s` 是字符串格式控制符。
- `scanf("%s", buf)` 不能接收空格。
- `printf("%s", buf)` 遇到 `'\0'` 停止打印。
- `gets` 可以从键盘接收空格，但不判断数组长度，会遇警告。
- fgets(str, n, stdin)可以也接收空格，可设置接受长度n，
  但会接受回车，可使用`str[strcspn(str, "\n")] = 0;`手动去掉回车
- `gets(buf);` 用于输入字符数组。
- `puts(buf);` 输出字符数组并自带换行。

### 字符串函数

以下函数需要包含 `<string.h>`。

#### strlen

```c
size_t strlen(const char *s);
```

求字符串长度，不包括 `'\0'`。

```c
char buf[32] = "hello world";
int len = strlen(buf);
int len = strlen("hello world");
```

#### strcmp

```c
int strcmp(const char *str1, const char *str2);
```

比较两个字符串。

- 返回值小于 0：`str1` 小于 `str2`。
- 返回值大于 0：`str1` 大于 `str2`。
- 返回值等于 0：两个字符串相等。

#### strcpy

```c
char *strcpy(char *dest, const char *src);
```

把 `src` 指向的字符串复制到 `dest`，包括 `src` 的 `'\0'`。目标数组必须足够大。

```c
char buf1[32] = "helloxyd";
char buf2[32] = "world";
strcpy(buf1, buf2);
printf("buf1:%s\n", buf1);
```

#### strcat

```c
char *strcat(char *dest, const char *src);
```

把 `src` 追加到 `dest` 的末尾。

```c
char buf1[32] = "hello";
char buf2[32] = "world";
strcat(buf1, buf2);
```

追加后 `buf1` 中为 `"helloworld"`。

## 注意点

- 自定义 `strcpy` 时，函数定义行末不能加分号；分号会把定义变成声明。复制过程要包含结尾的 `'\0'`，并返回原始目的地址。
- `assert` 是 `<assert.h>` 提供的断言宏，不是关键字。定义 `NDEBUG` 后断言可以失效，因此不能代替面向用户输入的运行时错误处理。
