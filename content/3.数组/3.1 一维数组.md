## 地址

定义变量后，计算机会为它开辟空间，这块空间在计算机中有地址。

```c
int a = 100;
scanf("%d", &a);
```

- `&` 是取地址符。
- 地址的格式控制符是 `%p`。


## 一维数组

需要存储多个相同类型的数据时，可以使用数组。

```c
int score[43];
```

数组特点：

1. 数组是相同类型元素的集合。
2. 数组开辟的地址空间是连续的。
3. 数组名是数组首元素的地址，也是整个数组的首地址。

```c
int num[5];
```

- 数组名是 `num`。
- 首元素是 `num[0]`。
- 首元素地址是 `&num[0]`。

### 定义和使用

```c
数据类型 数组名[数组长度];
```

```c
int num[5];
char buf[32];
float scores[10];

#define N 5
int values[N];
```

数组下标从 `0` 开始，范围是 `0` 到数组长度减 1。下标表示元素距离首元素的偏移量。

```c
num[0];
num[1];
num[2];
num[3];
num[4];
```

### 数组大小和长度

数组大小等于元素的数据类型大小乘以数组长度。

```c
int num[5];       // 4 * 5 = 20 字节
char buf[128];    // 1 * 128 = 128 字节
float scores[6];  // 4 * 6 = 24 字节
double values[4]; // 8 * 4 = 32 字节
```

使用sizeof()计算：

```c
sizeof(num);
sizeof(int[5]);
```

数组长度：

```c
sizeof(num) / sizeof(num[0])
```

### 数组初始化

```c
int num[5] = {1, 2, 3, 4, 5}; // 完全初始化
int num[5] = {1, 2};          // 部分初始化，未赋值元素为 0
int num[] = {1, 2, 3};        // 省略长度，按初始化内容确定长度
int num[5] = {0};             // 只定义不赋值时常用的局部数组写法
```

数组只有在定义时可以进行集体赋值，其他情况下只能对单个元素赋值。


## 冒泡排序

课件原例使用数组 `{8, 6, 4, 7, 2}`：

```c
#include <stdio.h>

#define N 5

int main()
{
    int num[N] = {8, 6, 4, 7, 2}, i = 0, j = 0;
    int tmp = 0;

    printf("排序前\n");
    for (i = 0; i < N; i++)
    {
        printf("%d", num[i]);
    }
    printf("\n");

    for (i = 0; i < 5 - 1; i++) // 控制循环次数
    {
        for (j = 0; j < 5 - 1 - i; j++)
        {
            if (num[j] > num[j + 1])
            {
                tmp = num[j];
                num[j] = num[j + 1];
                num[j + 1] = tmp;
            }
        }
    }

    printf("排序后\n");
    for (i = 0; i < N; i++)
    {
        printf("%d", num[i]);
    }
    printf("\n");

    return 0;
}
```

## 注意点

- `#define NTBL(table) (sizeof(table) / sizeof(table[0]))` 只是自定义宏。`table` 必须是完整数组类型；数组作为函数参数后会退化为指针，此时不能再用该宏求元素个数。
- 闭区间二分查找使用 `low <= high`，移动边界时写作 `high = mid - 1`、`low = mid + 1`。也可以使用 `mid = low + (high - low) / 2` 避免 `low + high` 溢出。
