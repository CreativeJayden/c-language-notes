## 共用体

共用体的所有成员共用一块内存，同一时间只能使用一个成员。

### 共用体的定义

```c
union 共用体名字
{
    成员1;
    成员2;
    成员3;
};
```

先定义类型，再定义变量：

```c
union Tag
{
    char name[24];
    int id;
    float score;
};

union Tag s1;
```

定义类型的同时定义变量，或定义无名共用体：

```c
union Tag
{
    char name[24];
    int id;
    float score;
} s1, s2;

union
{
    char name[24];
    int id;
    float score;
} s1, s2;
```

### 取成员

使用 `.` 取成员：

```c
s1.name;
s1.id;
s1.score;
```

### 共用体的大小

1. 确定对齐方式，方法同结构体。
2. 只需要最大的成员大小满足对齐方式的整数倍。

### 测试大小端

大端：高字节存放到内存的低地址。  
小端：高字节存放到内存的高地址。

```c
#include <stdio.h>
#include <string.h>

union Tag
{
    unsigned int a;
    unsigned char ch[4];
};

int main()
{
    union Tag test = {0};
    test.a = 0x12345678;

    printf("&a:%p\n", &test.a);
    for (int i = 0; i < 4; i++)
    {
        printf("ch[%d]:%p-----%#x\n",
               i, &test.ch[i], test.ch[i]);
    }

    if (test.ch[0] == 0x78)
    {
        printf("小端模式\n");
    }
    else
    {
        printf("大端模式\n");
    }

    return 0;
}
```

课件还使用指针偏移测试大小端：

```c
unsigned int a = 0x12345678;
unsigned char *p = (unsigned char *)&a;
```
