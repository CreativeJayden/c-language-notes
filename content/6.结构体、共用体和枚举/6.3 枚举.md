## 枚举

枚举用于批量定义整型常量。

```c
enum 名字
{
    成员1,
    成员2,
    成员3
};
```

### 枚举的定义

```c
enum Day
{
    Mon, Tue, Wed, Thu, Fri, Sat, Sun
};

enum Day day;
```

```c
enum Day
{
    Mon, Tue, Wed, Thu, Fri, Sat, Sun
} day;
```

```c
enum
{
    Mon, Tue, Wed, Thu, Fri, Sat, Sun
} day;
```

### 枚举的大小

枚举的大小可能是 4 个字节或 8 个字节，主要看成员的数值大小。

### 枚举的使用

```c
enum Day
{
    Mon, Tue, Wed, Thu, Fri, Sat, Sun
};
```

成员依次对应：

```text
0 1 2 3 4 5 6
```

```c
enum Day
{
    Mon = 1, Tue, Wed, Thu, Fri, Sat, Sun
};
```

成员依次对应：

```text
1 2 3 4 5 6 7
```

```c
enum Day
{
    Mon = 1, Tue, Wed, Thu = 66, Fri, Sat, Sun
};
```

成员依次对应：

```text
1 2 3 66 67 68 69
```
