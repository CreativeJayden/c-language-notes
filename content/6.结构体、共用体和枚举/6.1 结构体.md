## 结构体

需求：存储学生信息，包括姓名（字符串）、学号（整型）和成绩（浮点型）。

结构体也是一种数据类型，属于构造数据类型，是不同类型元素的集合。

### 结构体的定义

```c
struct 结构体名字
{
    成员1;
    成员2;
    成员3;
};
```

先定义类型，再定义变量：

```c
struct Stu
{
    char name[20];
    int id;
    float score;
};

struct Stu s1, s2;
```

定义类型的同时定义变量：

```c
struct Stu
{
    char name[20];
    int id;
    float score;
} s1, s2;

struct Stu s3;
```

无名结构体只能在定义类型的时候定义变量：

```c
struct
{
    char name[20];
    int id;
    float score;
} s1, s2;
```

### 取成员

普通结构体变量使用 `.`：

```c
struct Stu s1;
s1.name;
s1.id;
s1.score;
```

结构体指针使用 `->`：

```c
struct Stu s1;
struct Stu *p = &s1;

p->name;
p->id;
p->score;
```

### 初始化

```c
struct Stu s1 = {"王五", 123456, 88};
struct Stu s1 = {"王五"};
struct Stu s1 = {.name = "王五", .score = 100};
struct Stu s1 = {0};
```

- 完全初始化：按顺序给每个成员赋值。
- 部分初始化：未赋值的成员默认为 0。
- 取成员初始化：通过成员名字指定赋值。
- 局部变量通常写 `struct Stu s1 = {0};`。

### 结构体的大小

```c
struct Stu s1 = {0};
sizeof(s1);
sizeof(struct Stu);
```

计算结构体大小时：

1. 确定对齐方式，取以下三者中的最小值：
   - 64 位操作系统为 8 字节，32 位操作系统为 4 字节。
   - 结构体成员中最大的数据类型大小，遇到数组看元素大小。
   - 手动设置的对齐方式。`#pragma pack(N)` 可以设置新的对齐值，`N` 可为 1、2、4、8、16，一般不设置。
2. 除第一个成员外，其余成员距离首地址的偏移量，应该是对齐方式或自身大小两者中较小者的整数倍，遇到数组看元素。
3. 整个结构体的大小应该满足对齐方式的整数倍。

### 结构体数组

数组的元素都是结构体。

```c
struct 结构体名字 变量名[数组长度];
```

```c
struct Stu
{
    char name[20];
    int id;
    float score;
};

struct Stu student[3] =
{
    {"张三", 111, 88},
    {"李四", 222, 99},
    {"王五", 333, 100}
};
```

### typedef 类型重定义

```c
typedef 原有的数据类型名字 新的名字;
```

```c
typedef int my_int;
```

## 注意点

- 直接把结构体按二进制写入文件，会把填充字节、字节序和当前 ABI 的布局一起写入，不适合作为稳定的跨平台文件格式。相关读写见 [[9.2 格式化与二进制读写]]。
