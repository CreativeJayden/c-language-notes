## 函数的基本概念

函数用于封装可以实现某些功能的代码，减少代码冗余。

### 函数分类

- 主函数：`main` 函数，有且仅有一个，程序始于 `main`，终于 `main`。
- 库函数：官方封装好的函数，例如 `scanf`、`printf`、`strlen`、`strcat`、`strcpy`、`strcmp`。
- 第三方库函数：例如单片机标准库函数。
- 自定义子函数：自己编写的实现某些功能的代码。


## 自定义子函数

函数分为三步：定义、声明和调用。

### 函数的定义

```c
返回值的数据类型 函数名(形参类型 形参名)
{
    函数体;
    return 返回值;
}
```

- 有返回值时，返回值的数据类型和返回值保持一致。
- 没有返回值时，返回值类型写 `void`，`return` 后可以不写内容，也可以省略 `return`。
- 函数名遵循标识符命名规则。
- 无形参时括号里写 `void` 或省略。
- 有形参时，形参类型和形参名必须一一对应。
- 形参相当于函数内部的局部变量，可以直接使用。

函数可以分为四类：

1. 无参无返
2. 有参无返
3. 无参有返
4. 有参有返

### 函数的声明

声明用于告知编译器函数存在：

```c
函数头;
```

谁调用该函数，声明就放在谁的上方。函数声明一般放在 `main` 函数上方或头文件 `.h` 中。

如果函数定义在 `main` 函数上方，可以省略声明。

### 函数的调用

```c
函数名();
函数名(实参);
返回值的数据类型 变量名 = 函数名();
返回值的数据类型 变量名 = 函数名(实参);
```

形参和实参的关系：

1. 形参的起始值来自实参。
2. 形参和实参可以同名，也可以不同名。
3. 形参和实参具有不同的内存空间。
4. 形参和实参必须一一对应。

课件中的四种函数定义和调用：

```c
#include <stdio.h>

void Fun1();
void Fun2(int a, float b);
int Fun3();
int Fun4(int a, int b);

int main()
{
    int a = 3;
    float b = 7.89;

    Fun1();
    Fun2(a, b);
    printf("该函数的返回值为%d\n", Fun3());
    printf("两数之和:%d\n", Fun4(5, 8));

    return 0;
}

void Fun1()
{
    printf("i am 无参无返函数\n");
}

void Fun2(int a, float b)
{
    printf("i am 有参无返函数,a=%d,b=%.2f\n", a, b);
}

int Fun3()
{
    int a = 0;
    printf("i am 无参有返函数\n");
    scanf("%d", &a);
    return a;
}

int Fun4(int a, int b)
{
    return a + b;
}
```


## 函数的传参

### 值传递

形参和实参具有不同的内存空间，形参改变不会引起实参改变。

```c
void Swap(int a, int b);
```

### 地址传递

直接传递变量的地址，形参和实参操作同一块地址，子函数中形参的改变会引起主函数中实参的改变。

```c
void Swap(int *a, int *b);

int a = 0, b = 0;
Swap(&a, &b);
```

### 数组传参

数组传参的本质是地址传递，传递的是数组首元素地址。

传递定长数组：

```c
int Get_Sum(int num[5]);
```

传递不定长数组：

```c
int Get_Sum(int num[], int n);

int len = sizeof(num) / sizeof(num[0]);
Get_Sum(num, len);
```

传递指针：

```c
int Get_Sum(int *p, int n);
```

## 注意点

- C 函数参数一律按值传递。所谓“地址传递”，传入的也是指针变量的副本，只是函数可以通过这个地址间接修改调用者的对象。
- 数组传参后，形参会退化为指针；在被调函数中对参数使用 `sizeof` 不能得到原数组的总字节数。
- 自定义 `strcpy` 等函数时，函数定义行末不能加分号。相关说明见 [[3.2 字符数组与字符串]]。
