## 函数和指针

指针数组、数组指针、函数指针、函数指针数组和指针函数的关系汇总在 [[#指针一览表|指针一览表]]。

### 指针函数

本质是函数，返回值是指针。

```c
char *strcat(char *dest, const char *src);
void *malloc(size_t size);
```

`void *` 是万能指针，可以强转为其他类型的指针。

### 函数指针

本质是指针，指针指向函数。定义函数指针时，函数名可以直接当地址使用。

```c
void Fun(void);
void (*p)(void) = Fun;

p();
Fun();
```

函数指针常用的地方是作为函数参数。

### 函数指针数组

本质是数组，数组中存放函数指针。

```c
数据类型 (*指针名[数组长度])(形参类型) =
{
    函数名1,
    函数名2,
    函数名3
};
```

课件要求编写简单计算器，键盘输入 `7 + 8`，输出 `7 + 8 = 15`，并把加减乘除封装成函数，用函数指针数组实现。代码如下：

```c
#include <stdio.h>
#include <string.h>

int Add(int a,int b);
int Sub(int a,int b);
int Mul(int a,int b);
int Div(int a,int b);
int main()
{
    int a = 0,b = 0,i = 0;
    char ch = 0;
    int (*p[])(int,int) = {Add,Sub,Mul,Div};
    printf("请输入a+b的形式\n");
    scanf("%d%c%d",&a,&ch,&b);
    switch(ch)
    {
        case '+':i = 0;break;
        case '-':i = 1;break;
        case '*':i = 2;break;
        case '/':i = 3;break;
        default:printf("输入的格式有误\n");break;
    }
    printf("%d%c%d=%d\n",a,ch,b,p[i](a,b));
    return 0;
}

int Add(int a,int b)
{
    return a+b;
}

int Sub(int a,int b)
{
    return a-b;
}

int Mul(int a,int b)
{
    return a*b;
}

int Div(int a,int b)
{
    return a/b;
}
```
指针数组和数组指针的基础用法见 [[4.2 指针与数组]]，复杂声明见 [[4.3 复杂声明与 const]]；五类声明的统一对照见 [[#指针一览表|指针一览表]]。

## 指针一览表

| 名称     | 本质     | 典型声明                     | 从变量名向外读                                | 典型用法                                               |
| ------ | ------ | ------------------------ | -------------------------------------- | -------------------------------------------------- |
| 指针数组   | **数组** | `int *a[5];`             | `a` 先结合 `[]`：有 5 个元素的数组，元素类型是 `int *`  | `a[0] = &x;`；字符串数组 `const char *s[3]`              |
| 数组指针   | **指针** | `int (*p)[5];`           | `(*p)` 让 `p` 先结合 `*`：指针，指向完整的 `int[5]` | `int row[5]; p = &row; (*p)[2] = 7;`；`p + 1` 跨过一整行 |
| 函数指针   | **指针** | `int (*p)(int, int);`    | `p` 是指针，指向“接收两个 `int`、返回 `int`”的函数     | `pf = add; pf(2, 3);`；回调函数                         |
| 函数指针数组 | **数组** | `int (*p[3])(int, int);` | `p[3]` 是数组，每个元素都是上述函数指针                | `ops[0] = add; ops[0](2, 3);`；菜单、分发表               |
| 指针函数   | **函数** | `int *p(int);`           | `p(int)` 是函数，左边的 `*` 属于返回类型，返回 `int *` | `return &a[i];`；标准库 `malloc` 返回 `void *`           |

## 注意点

- `int (*operation)(int, int)` 是函数指针，保存函数的地址。
- `int (*operations[2])(int, int)` 中的 `operations` 先和 `[]` 结合，是函数指针数组。
- `int *find_value(...)` 是指针函数，本质是函数，返回值是指针。
- 把整数地址转换为函数指针属于实现定义行为；调用没有正确映射且不可执行的地址属于未定义行为。
