## 函数和指针

### 指针函数

本质是函数，返回值是指针。

```c
char *strcat(char *dest, const char *src);
void *malloc(size_t size);
```

`void *` 是万能指针，可以强转为其他类型的指针。

### 函数指针

本质是指针，指针指向函数。定义函数指针时，函数名可以直接当地址使用。

```c
void Fun(void);
void (*p)(void) = Fun;

p();
Fun();
```

函数指针常用的地方是作为函数参数。

### 函数指针数组

本质是数组，数组中存放函数指针。

```c
数据类型 (*指针名[数组长度])(形参类型) =
{
    函数名1,
    函数名2,
    函数名3
};
```

课件要求编写简单计算器，键盘输入 `7 + 8`，输出 `7 + 8 = 15`，并把加减乘除封装成函数，用函数指针数组实现。完整实现见 [function_pointer_calculator.c](../示例代码/function_pointer_calculator.c)；这是对课件计算器要求的补充示例。

指针函数、函数指针、函数指针数组和指针数组的交叉关系见 [[4.3 复杂声明与 const]]。

## 注意点

- `int (*operation)(int, int)` 是函数指针，保存函数的地址。
- `int (*operations[2])(int, int)` 中的 `operations` 先和 `[]` 结合，是函数指针数组。
- `int *find_value(...)` 是指针函数，本质是函数，返回值是指针。
- 指针数组、数组指针、函数指针、函数指针数组、指针函数的交叉关系，可在 [[4.3 复杂声明与 const]] 与本页之间对照。
- 把整数地址转换为函数指针属于实现定义行为；调用没有正确映射且不可执行的地址属于未定义行为。
