## static 关键字

局部变量每次调用结束后空间会被释放，再次调用时重新开辟空间。

`static` 可以：

1. 修饰局部变量，延长生命周期。
2. 修饰全局变量，表示私有化，只能在当前 `.c` 文件使用。
3. 修饰函数，表示私有化。

不要返回局部变量的地址。


## 函数递归

递归是函数在函数体内调用自身。递归必须有两个要素：

1. 结束条件。
2. 递推关系。

课件中的阶乘递归：

```c
#include <stdio.h>

int Fun(int n);

int main()
{
    int a = 0;
    printf("请输入你要求几的阶乘\n");
    scanf("%d", &a);
    printf("%d 的阶乘为%d\n", a, Fun(a));
    return 0;
}

int Fun(int n)
{
    int num = 0;

    if (n == 1)
    {
        num = 1;
    }
    else if (n > 1)
    {
        num = n * Fun(n - 1);
    }

    return num;
}
```

递归每次调用都要保存局部变量、形参、调用函数地址和返回值，递归次数多时效率较低。

## 注意点

- 函数内部的 `static` 局部变量具有静态存储期，只在首次进入时初始化，之后保留上次的值。
- 文件作用域的 `static` 主要改变链接属性，使名字只在当前翻译单元内可见。它与函数内 `static` 局部变量的侧重点不同。跨文件访问见 [[7.3 extern 与位操作]]。
