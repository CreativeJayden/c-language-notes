## 九大语句

- 顺序结构：从上往下顺序执行。
- 条件选择：`if...else`、`switch...case`。
- 循环处理：`for`、`while`、`do...while`。
- 特殊控制：`break`、`continue`、`return`、`goto`。


## if...else 语句

### 单分支

```c
if (表达式)
{
    语句;
}
```

表达式为真时执行语句，否则不执行。

### 双分支

```c
if (表达式)
{
    语句1;
}
else
{
    语句2;
}
```

表达式为真时执行语句 1，否则执行语句 2。

### 多分支

```c
if (表达式1)
{
    语句1;
}
else if (表达式2)
{
    语句2;
}
else
{
    语句3;
}
```

依次判断表达式，前面的条件成立后执行对应语句；所有条件都不成立时执行 `else`。

课件示例：

```c
#include <stdio.h>

int main()
{
    int score = 0;
    printf("请输入你的成绩\n");
    scanf("%d", &score);

    if (score >= 90)
    {
        printf("优秀\n");
    }
    else if (score < 90 && score >= 80)
    {
        printf("良好\n");
    }
    else if (score < 80 && score >= 70)
    {
        printf("中等\n");
    }
    else if (score < 70 && score >= 60)
    {
        printf("及格\n");
    }
    else
    {
        printf("你怎么睡的着呢????\n");
    }

    return 0;
}
```

注意事项：

1. 大括号省略时，只执行条件判断后的一行代码。
2. 多个单分支语句会依次判断每个表达式。


## switch...case 语句

```c
switch (表达式)
{
case 常量1:
    语句1;
    break;
case 常量2:
    语句2;
    break;
default:
    语句3;
    break;
}
```

根据表达式的结果执行对应的 `case`。
所有情况都不满足时执行 `default`，`default` 不是必须存在。
`break` 也不是必须的，不添加代表一直往下执行。

经典用法

```c
#include <stdio.h>
int main()
{
    int year,month,day,sum = 0;
    printf("请输入年月日\n");
    scanf("%d%d%d", &year, &month, &day);
    switch(month)
    {
        case 12:sum += 30;
        case 11:sum += 31;
        case 10:sum += 30;
        case 9:sum += 31;
        case 8:sum += 31;
        case 7:sum += 30;
        case 6:sum += 31;
        case 5:sum += 30;
        case 4:sum += 31;
        case 3:
            if((!(year % 4) && (year % 100 != 0)) || !(year % 400))
                sum+=29;
            else
                sum+=28;
        case 2:sum+=31;
        case 1:sum+=day;
    }
    printf("%d年%d月%d日是这一年的第%d天\n",year,month,day,sum);
    return 0;
}
```


## 注意点

- `==` 的优先级高于 `=`。在 `if` 中先赋值再判断时，要写成 `if ((ptr = malloc(sizeof *ptr)) == NULL)`，否则容易把比较误写成赋值。
