## for 循环

```c
for (条件的初始值; 条件的判断; 条件的改变)
{
    循环体;
}
```

先进行条件判断；为真时执行循环体，再进行条件改变，然后再次判断。

条件判断为假时跳出 `for` 循环。


## while 循环

```c
while (条件的判断)
{
    循环体;
    条件的改变;
}
```

先判断条件，为真时执行循环体，再次判断，直到条件为假。


## do...while 循环

```c
do
{
    循环体;
    条件的改变;
} while (条件的判断);
```

`while` 先判断后执行，`do...while` 先执行后判断。


## 死循环

```c
for (;;)
{
    循环体;
}

while (1)
{
    循环体;
}
```


## 循环嵌套

外层循环执行一次，内层循环执行一遍。

## 注意点

- 使用 `high = mid - 1` 和 `low = mid + 1` 的闭区间二分查找，循环条件应写成 `low <= high`；写成 `low < high` 会漏掉 `low == high` 时的最后一个候选元素。相关例子见 [[3.1 一维数组]]。
