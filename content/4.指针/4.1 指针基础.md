## 指针的概念

指针也是一种数据类型，属于构造数据类型，专门用来存放地址。

```c
int a = 100;
printf("&a=%p\n", &a);
```

`&a` 取出变量 `a` 的地址。


## 指针的类型表达

```c
指针指向的空间类型 *指针名;
```

```c
int a = 100;
int *p = &a;

char ch = 'A';
char *p = &ch;

float num = 1.23;
float *p = &num;
```

- `a` 的类型是 `int`，`&a` 的类型是 `int *`。
- 指针中存放谁的地址，就表示指针指向谁。


## 指针的大小

- 64 位操作系统下，指针固定为 8 字节。
- 32 位操作系统下，指针固定为 4 字节。

`int *`、`char *`、`float *`、`double *`、`long *` 在同一个平台下大小相同。


## 解指针

通过指针操作它指向的空间中存放的内容：

```c
*指针名
```

```c
int a = 100;
int *p = &a;
*p = 66;
```


## 野指针和空指针

- 野指针：没有指向的指针，一定要避免野指针。
- 空指针：指向 0 号地址的指针。

```c
int *p = NULL;
```

- 全局指针不赋值时默认为 `NULL`。
- 局部指针不赋值时是野指针。


## 指针偏移

指针偏移以指针指向的空间大小为单位。

```c
int *p;
p + 1;
```

`p + 1` 按一个 `int` 的大小移动，而不是只移动一个字节。


## 二级指针

```c
int a = 100;
int *p = &a;
int **q = &p;
int ***w = &q;
```

- `p` 是一级指针，存放 `a` 的地址。
- `q` 是二级指针，存放 `p` 的地址。
- `w` 是三级指针，存放 `q` 的地址。

二级指针的偏移以它指向的空间大小为单位。

```c
q + 1;
```

`q` 指向的空间类型是 `int *`，在 64 位系统下 `q + 1` 加 8 字节。


## C 语言五大区

1. 堆区
2. 栈区
3. 全局/静态存储区
4. 常量区
5. 代码段

```c
char buf[] = "hello world";
char *p = "hello world";
```

- `buf` 是数组，内容存放在栈区。
- `p` 中存放常量区字符串首元素 `h` 的地址。
- 常量区的内容不能更改。
- `sizeof(buf)` 为 12，`sizeof(p)` 为 8。
- `p` 可以执行 `p++`，数组名 `buf` 不能执行 `buf++`。

```c
char buf1[3][80] = {"hello", "world", "xyd"};
char *buf2[3] = {"hello", "world", "xyd"};
```

```text
sizeof(buf1)    = 240
sizeof(buf1[0]) = 80
sizeof(buf2)    = 24
sizeof(buf2[0]) = 8
```

## 注意点

- “栈、堆、常量区、代码区”是常见实现和教材中的描述，不是 C 标准统一规定的分区；标准关注的是存储期、作用域、链接属性和可修改性。
- `malloc(0)` 可以返回空指针，也可以返回一个非空但不可解引用的指针；标准没有给出唯一结果。
