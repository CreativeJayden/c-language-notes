## 指针定义总结

```c
/*指针*/
int *p = NULL; // 空指针

int a = 100;
int *p = &a; // 指针指向a
/*数组指针*/
int num[5] = {1, 2, 3, 4, 5};
int *p = num; // 指针指向数组num的首元素
int *p = &num[0]; // 同上
/*字符指针*/
char buf[] = "hello world";
buf[2] = 'E'; // 给字符串第三元素赋值
*(buf + 2) = 'E'; // 同上

char *p = "hello world"; // 指针指向位于常量区字符串首元素h
p++; // 指针向后偏移一个char,指向e
printf("%s\n", p + 2); // 从第二个l开始输出 lo world
printf("%p\n", p + 6); // 输出常量区o的地址
printf("%c\n", *(p + 6)); // 输出o
/*二维数组指针*/
int num[2][3] = {0};
int (*p)[3] = num; // 指向int[3]类型的指针
```


## const 关键字

`const` 修饰谁，谁只读。

```c
const int a = 100;
// a = 66; 错误

int a = 100;
const int *p = &a;
// *p = 66; 错误
// a = 66; 正确

int a = 100, b = 200;
int *const p = &a;
*p = 66;
// p = &b; 错误

const int *const p = &a;
// p 和 *p 都不能更改
```

指针数组、数组指针、函数指针、函数指针数组和指针函数的区别见 [[5.3 函数指针#指针一览表|指针一览表]]。

## 注意点

- `int *values[2]` 中的 `values` 先和 `[]` 结合，是[[5.3 函数指针#指针一览表|指针数组]]，数组元素类型是 `int *`。
- `int (*p)[3]` 中的 `p` 先和 `*` 结合，是[[5.3 函数指针#指针一览表|数组指针]]，指向整个 `int[3]`。
- `int (*operation)(int, int)` 中的 `operation` 是[[5.3 函数指针#指针一览表|函数指针]]，指向一个接收两个 `int` 并返回 `int` 的函数。
- `int (*operations[2])(int, int)` 中的 `operations` 先和 `[]` 结合，是[[5.3 函数指针#指针一览表|函数指针数组]]。
- `int *find_value(...)` 先和 `()` 结合，是[[5.3 函数指针#指针一览表|指针函数]]，本质是函数，返回值类型为 `int *`。
- 遇到复杂声明时，先找到标识符，再看它先与 `*`、`[]` 还是 `()` 结合。完整对照见 [[5.3 函数指针#指针一览表|指针一览表]]。
