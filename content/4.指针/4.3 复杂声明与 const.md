## 指针定义总结

```c
int *p = NULL;

int a = 100;
int *p = &a;

int num[5] = {1, 2, 3, 4, 5};
int *p = num;
int *p = &num[0];

char buf[] = "hello world";
buf[2] = 'E';
*(buf + 2) = 'E';

char *p = "hello world";
p++;
printf("%s\n", p + 2);
printf("%p\n", p + 6);
printf("%c\n", *(p + 6));

int num[2][3] = {0};
int (*p)[3] = num;
```


## const 关键字

`const` 修饰谁，谁只读。

```c
const int a = 100;
// a = 66; 错误

int a = 100;
const int *p = &a;
// *p = 66; 错误
// a = 66; 正确

int a = 100, b = 200;
int *const p = &a;
*p = 66;
// p = &b; 错误

const int *const p = &a;
// p 和 *p 都不能更改
```

函数指针和函数指针数组的用法见 [[5.3 函数指针]]。

## 注意点

- `int *values[2]` 中的 `values` 先和 `[]` 结合，是指针数组，数组元素类型是 `int *`。
- `int (*p)[3]` 中的 `p` 先和 `*` 结合，是数组指针，指向整个 `int[3]`。
- `int (*operation)(int, int)` 中的 `operation` 是函数指针，指向一个接收两个 `int` 并返回 `int` 的函数。
- `int (*operations[2])(int, int)` 中的 `operations` 先和 `[]` 结合，是函数指针数组。
- `int *find_value(...)` 先和 `()` 结合，是指针函数，本质是函数，返回值类型为 `int *`。
- 遇到复杂声明时，先找到标识符，再看它先与 `*`、`[]` 还是 `()` 结合。完整用法见 [[5.3 函数指针]]。
