## 指针和数组

### 指向数组元素的指针

```c
int num[5] = {1, 2, 3, 4, 5};
int *p = num;
int *p = &num[0];
```

- `num` 等价于 `&num[0]`。
- `num[0]` 的类型是 `int`。
- `&num[0]` 的类型是 `int *`。
- 下标表示元素距离首地址的偏移量。
- `[]` 暗含解指针操作。

```c
char buf[32] = "hello world";
char *p = buf;
```

```c
p + 1;       // 字符 e 的地址
*(p + 2);    // 第一个字符 l
buf + 3;     // 第二个 l 的地址
*(buf + 4);  // 第一个字符 o
```

### 指针和二维数组

二维数组的本质是一维数组，二维数组中的元素是一维数组。

```c
int num[3][4];
int (*p)[4] = num;
```

`num` 有三个元素：`num[0]`、`num[1]`、`num[2]`。

`p` 是[[5.3 函数指针#指针一览表|数组指针]]，指向由 4 个 `int` 组成的一维数组；`p + 1` 会跨过一整行。

取二维数组元素的8种方法：

`num[i][j]`  `(*(num + i))[j]` `*(num[i] + j)` `*(*(num + i) + j)`
`p[i][j]`     `(*(p + i))[j]`     `*(p[i] + j)`     `*(*(p + i) + j)`
## 指针数组

指针数组本质是数组，数组中的元素都是指针。

指针数组、数组指针、函数指针、函数指针数组和指针函数的对照见 [[5.3 函数指针#指针一览表|指针一览表]]。

```c
int a, b, c;
int *p1 = &a;
int *p2 = &b;
int *p3 = &c;
int *ptr[3] = {p1, p2, p3};
```

指针数组使用较多的地方是字符串数组：

```c
char buf1[32] = "nihao";
char buf2[32] = "hello";
char buf3[32] = "zaiganma";

char *p1 = buf1;
char *p2 = buf2;
char *p3 = buf3;
char *ptr[3] = {p1, p2, p3};
```

```c
char buf1[3][80] = {"hello", "world", "xyd"};
char *buf2[3] = {"hello", "world", "xyd"};  // 3个字符指针，分别指向常量区的h,w,x的地址
```

## 注意点

- 指针加整数按所指对象的大小移动：`p + n` 的地址等于 `p` 的地址加 `n * sizeof(*p)`。
- [[5.3 函数指针#指针一览表|指针数组]]是数组，元素类型才是指针；[[5.3 函数指针#指针一览表|数组指针]]是指针，指向整个数组类型。两者的声明要结合 `[]`、`()` 和 `*` 的优先级来读。
