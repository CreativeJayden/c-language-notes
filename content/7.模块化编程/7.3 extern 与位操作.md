## extern 关键字

1. 修饰全局变量，表示变量来自外部，声明时不能赋值。
2. 修饰函数，表示函数来自外部，一般省略不写。

例如在 `1.c` 中定义变量，想在 `2.c` 中使用，需要在 `2.c` 中写外部声明：

```c
extern 数据类型 变量名;
```

编译时要编译所有 `.c` 文件，不要编译 `.h` 文件。出现 `.gch` 文件导致问题时，删除所有 `.gch` 文件后重新编译。


## 位操作

位运算符包括 `&`、`|`、`^`、`~`、`<<`、`>>`，专门针对二进制数。

- `&` 按位与：与 0 为 0，与 1 不变。
- `|` 按位或：或 1 置 1，或 0 不变。
- `^` 按位异或：相同为 0，不同为 1。
- `~` 按位取反：0 变 1，1 变 0。

异或的规律：

```text
1 ^ 1 = 0
0 ^ 1 = 1
1 ^ 0 = 1
0 ^ 0 = 0
```

异或 1 取反，异或 0 不变。

### 位操作公式

```c
value |= 1 << n;    // 第 n 位置 1，其他位不变
value &= ~(1 << n); // 第 n 位清 0，其他位不变
value ^= 1 << n;    // 第 n 位取反，其他位不变
```

## 注意点

- 文件作用域的 `static` 主要改变链接属性，使名字只在当前翻译单元内可见；普通全局变量和 `static` 全局变量都具有静态存储期。
- 位运算公式只修改指定的位，其余位保持不变。位运算基础见 [[1.3 运算符]]。
