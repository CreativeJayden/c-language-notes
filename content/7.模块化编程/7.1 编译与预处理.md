## 编译流程

使用 `gcc` 编译 C 文件：

```sh
gcc 1.c
gcc 1.c -o 111
```

- `gcc 1.c` 默认生成 `a.out`。
- `gcc 1.c -o 111` 指定生成的可执行程序名为 `111`。

编译流程分为四步：

```sh
gcc -E 1.c -o 1.i
gcc -S 1.i -o 1.s
as 1.s -o 1.o
gcc 1.o -o 111
```

1. 预处理：处理伪指令，也就是代码中以 `#` 开头的语句。
2. 编译：转为汇编。
3. 汇编：转为二进制目标文件。
4. 链接：链接库，生成可执行程序。

## 预处理命令

预处理命令不需要在语句末尾加分号。

### #define

```c
#define 宏名 宏体
```

宏体会原样替换。

```c
#define N 50
#define 宏名
```

## 注意点

- “预处理”和“预编译头 PCH”不是同一个概念。普通编译每次都会执行预处理。
- `#define` 只是文本替换，不会进行类型检查；展开后要注意括号和副作用。
- `NTBL(table)` 只有在 `table` 仍是完整数组类型时才能正确计算元素个数；数组传参后退化为指针，不能再直接用该宏求长度。相关写法见 [[3.1 一维数组]]。
