## 树和二叉树

树型结构是以分支关系定义的层次结构，是一种非线性结构。家庭族谱、社会组织机构和计算机文件管理中的目录都可以用树形结构表示。

树是由一个或多个结点组成的有限集合 `T`：

- 有一个特定的结点称为根结点。
- 除根结点外的其余结点可以分为 `m` 个互不相交的有限集合，每个集合本身又是一棵树，称为根的子树。
- 根结点没有前驱结点，其他结点有且只有一个前驱结点；每个结点可以有零个或多个后继结点。

### 基本术语

- 结点的度：一个结点拥有的子树数目。
- 树的度：树中所有结点度的最大值。
- 叶子结点：度为 `0` 的结点，也叫终端结点。
- 分支结点：度不为 `0` 的结点，也叫非终端结点。
- 孩子结点：某个结点的子树之根。
- 双亲结点：孩子结点的上层结点。
- 兄弟结点：同一个双亲的孩子结点。
- 结点的层数：根为第 `1` 层，根的孩子为第 `2` 层，依次向下递增。
- 树的高度或深度：树中结点的最大层数。
- 有序树：每个结点的各子树从左到右有次序，不能互换。

### 二叉树

二叉树是 `n(n >= 0)` 个结点的有限集合。它或者为空集，或者由一个根结点及两棵互不相交的左子树、右子树组成，并且左子树和右子树本身也都是二叉树。

二叉树的左子树和右子树严格区分，不能随意颠倒。

二叉树的性质：

- 第 `i` 层最多有 `2^(i-1)` 个结点，`i >= 1`。
- 深度为 `k` 的二叉树最多有 `2^k - 1` 个结点，`k >= 1`。
- 叶子结点数为 `n0`，度为 `1` 的结点数为 `n1`，度为 `2` 的结点数为 `n2`，则 `n0 = n2 + 1`。

### 满二叉树和完全二叉树

满二叉树：深度为 `k` 且有 `2^k - 1` 个结点的二叉树。每一层的结点数都达到最大值，不存在度为 `1` 的结点。

完全二叉树：最多只有最下面两层结点的度可以小于 `2`，并且最下面一层的结点都集中在最左边的若干位置。

- 满二叉树一定是完全二叉树。
- 完全二叉树不一定是满二叉树。
- 完全二叉树中，如果一个结点没有左孩子，那么它也一定没有右孩子。

### 顺序存储结构

二叉树可以存放在一维数组中。课件采用从下标 `1` 开始存放根结点的方式，下标 `0` 闲置。

```c
#define MAXSIZE 20
typedef char DATATYPE;
DATATYPE BT[MAXSIZE];
```

若结点存放在 `BT[i]`：

- 双亲结点为 `BT[i / 2]`。
- 左孩子结点为 `BT[2 * i]`。
- 右孩子结点为 `BT[2 * i + 1]`。

顺序存储结构对完全二叉树比较简单、节省空间；一般二叉树可能浪费大量数组空间，插入和删除结点时也可能需要移动大量元素。

### 链式存储结构

二叉链表中的每个结点包含一个数据域和两个指针域，分别指向左孩子和右孩子。

```c
typedef int DATATYPE;

typedef struct tagBTNODE
{
    DATATYPE data;
    struct tagBTNODE *lchild;
    struct tagBTNODE *rchild;
} BTNODE;
```

### 二叉树的遍历

二叉树的遍历是指按某条搜索路径访问树中的每一个结点，使每个结点都被访问一次并且只被访问一次。

- 先根遍历 `NLR`：根、左子树、右子树。
- 中根遍历 `LNR`：左子树、根、右子树。
- 后根遍历 `LRN`：左子树、右子树、根。

```c
void PreOrder(BTNODE *root)
{
    if (root != NULL)
    {
        printf("%d ", root->data);
        PreOrder(root->lchild);
        PreOrder(root->rchild);
    }
}

void InOrder(BTNODE *root)
{
    if (root != NULL)
    {
        InOrder(root->lchild);
        printf("%d ", root->data);
        InOrder(root->rchild);
    }
}

void PostOrder(BTNODE *root)
{
    if (root != NULL)
    {
        PostOrder(root->lchild);
        PostOrder(root->rchild);
        printf("%d ", root->data);
    }
}
```
