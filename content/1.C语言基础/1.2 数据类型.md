## 常量和变量

- 常量：程序运行过程中不会发生改变的量，例如 `88`、`"wqh"`。
- 变量：程序运行过程中可以发生改变的量，例如 `int a;`。

## 标识符

标识符用于给变量、函数等内容起名字。

1. 由数字、字母或下划线组成，数字不能开头。
2. 不能与关键字重复，例如 `int if;` 是错误的。
3. 区分大小写，例如 `A` 和 `a`、`Num` 和 `num` 不同。
4. 最好做到见词知意。

## 数据类型概念

数据可以分为整数、小数、字符和字符串。

- 基本数据类型：整型、浮点型、字符型。
- 构造数据类型：数组、指针、结构体、共用体、枚举。

## 整型

整型专门用来存放整数，关键字是 `int`，常用格式控制符是 `%d`。

```c
int num;
num = 100;

int num = 100;
```

赋值时，把等号右侧的值放入左侧变量。

课件在 64 位环境中的示例：

| 类型 | 大小 | 取值范围或格式 |
| --- | --- | --- |
| `unsigned int` | 4 字节，32 位 | `0` 到 `2^32-1`，即 `4294967295` |
| `signed int` | 4 字节，32 位 | `-2147483648` 到 `2147483647` |
| `short` | 2 字节，16 位 | 有符号范围 `-32768` 到 `32767` |
| `unsigned short` | 2 字节，16 位 | `0` 到 `65535` |
| `long` | 8 字节 | 格式控制符 `%ld` |
| `long long` | C99 标准下 8 字节 | 更大的整数范围 |

有符号整数的最高位是符号位：`0` 表示正数，`1` 表示负数。

```c
int num = 100;
```

定义整型变量 `num` 后，计算机会开辟 4 个字节的空间，把这块空间命名为 `num`，在里面存放整数 100。

## 浮点型

浮点型专门用来存放小数。

| 类型 | 大小 | 有效位数 | 格式控制符 |
| --- | --- | --- | --- |
| `float` | 4 字节 | 小数点后 6 到 7 位 | `%f` |
| `double` | 8 字节 | 小数点后 15 到 16 位 | `%lf` |

`printf` 默认打印到小数点后 6 位。

```c
printf("%.2f", value);
printf("%8.2f", value);
printf("%02d", number);
```

- `%.nf` 或 `%.nlf` 保留 `n` 位小数。
- `%±m.nf` 中，`m` 表示位宽。
- 正数表示右对齐，负数表示左对齐。
- `%8.2f` 表示位宽为 8，保留两位小数，右对齐。
- `%02d` 表示位宽为 2，数据不足两位时补 0。

## 字符型

字符型关键字是 `char`，占 1 个字节、8 位。

字符型既能表示整数，也能表示字符。

```c
char ch = 66;
printf("%d\n", ch);

char ch = 'A';
printf("%c\n", ch);
```

| 类型 | 取值范围 |
| --- | --- |
| `unsigned char` | `0` 到 `255` |
| `signed char` | `-128` 到 `127` |

单引号括起来的是字符，双引号括起来的是字符串。

```text
'A' 是字符
"A" 等价于 'A' 和 '\0'
```

要避免数据回环，应根据使用场景选择合适的数据类型。

数据类型的大小与编译目标有关。

## scanf 函数

`printf` 向屏幕打印，`scanf` 从键盘输入。

```c
scanf("格式控制符", 输入列表);
```

空格和回车都表示一个格式控制符的输入完成，最后一次输入后按回车。
因此，再进行字符串的输入时，也会采取以下两种方式
1. `gets(str)`
	优点：可接受空格 
	缺点：但会警告，因为输入长度可能超过定义的数组长度，产生越界
2. `fgets(str, sizeof(str), stdin)` 
	优点：可接收空格，并且不会越界
	缺点：回车需要手动去除，str[strcspn(str, "\n")] = 0

```c
int num;
scanf("%d", &num);

float num;
scanf("%f", &num);

double num;
scanf("%lf", &num);

char ch;
scanf("%c", &ch);
```

- `&` 是取地址符。
- `%d` 接收整数。
- `%f` 和 `%lf` 接收小数。
- `%c` 接收字符。

整型和字符型一起输入时，可以使用 `getchar()` 从输入缓冲区读取一个字符。

`scanf` 的双引号中只写格式控制符。

## 注意点

- `int` 的宽度由编译目标、数据模型和 ABI 决定，不能只根据处理器或操作系统的位数推断；需要确定宽度时使用 `sizeof(int)`。
- 不要假定 `unsigned int` 的最大值一定是 `0xFFFF`。需要最大值时可使用 `<limits.h>` 中的 `UINT_MAX`，或写成 `~0u`。
- 定义常量的两种方法：1. `#define N 100` 2. `int const num = 100;` 或 `const int num = 100;`
