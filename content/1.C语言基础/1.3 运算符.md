## 运算符分类

- 按操作数数量：单目运算符、双目运算符、三目运算符。
- 按功能：赋值、算术、关系、逻辑、逗号、复合、自加自减、条件、位、`sizeof`。

`'\hhh'` 表示八进制数 `hhh`，`'\xhh'` 表示十六进制数 `0xhh`。

## 赋值运算符

`=` 把右侧的值赋给左侧。

```c
int a = 100;
int b = a;
```

等号左侧不能是常量。

## 算术运算符

算术运算符包括 `+`、`-`、`*`、`/`、`%`。

运算符两侧数据类型不一致时，结果自动向精度更高的方向转换：

```text
double > float > int > char
```

```c
1 + 2       // 3
1 + 2.0     // 3.0
10 / 3      // 3
10 / 4      // 2
10 / 4.0    // 2.5
13 % 3      // 1
```

- 两个整数相除，结果是商。
- `%` 是取余，两侧必须是整数。

## 关系运算符

关系运算符包括 `>`、`>=`、`<`、`<=`、`==`、`!=`。

运算结果只有真 `1` 和假 `0`。

- `==` 比较两个值是否相等。
- `=` 用于赋值。

## 逻辑运算符

逻辑运算符包括 `&&`、`||`、`!`。

C 语言规定：`0` 为假，非 `0` 为真。

```c
expression1 && expression2
expression1 || expression2
!expression
```

- `&&`：两个表达式都为真时结果才为真。
- `&&` 左侧为假时，右侧不再参与运算。
- `||`：两个表达式中只要有一个为真，结果就为真。
- `||` 左侧为真时，右侧不再参与运算。
- `!`：真变假，假变真。

## 逗号运算符

逗号可以用于分隔。

```c
int a;
int b;
int c;
int a, b, c;
```

逗号与小括号连用时，整个逗号表达式的结果是最后一个表达式的结果。

```c
int a = (1, 2, 5, 7);
```

执行后 `a` 的值为 `7`。

## 复合运算符

```c
a += 2;  // 等价于 a = a + 2;
a %= 3;  // 等价于 a = a % 3;
```

## 自加自减运算符

- `++` 或 `--` 在前：先加或先减，再使用，例如 `++a`。
- `++` 或 `--` 在后：先使用，再加或减，例如 `a++`。

## 条件运算符

条件运算符是三目运算符。

```c
表达式1 ? 表达式2 : 表达式3
```

- 表达式 1 为真，整个表达式的结果是表达式 2。
- 表达式 1 为假，整个表达式的结果是表达式 3。

经典用法

```c
a > b ? a : b // 取两个数的最大值
```

## 位运算符

位运算符针对二进制数，包括 `&`、`|`、`~`、`^`、`<<`、`>>`。

### 按位与

与 0 为 0，与 1 不变。

```text
12 & 6
  1100
& 0110
------
  0100  -> 4
```

### 按位或

或 1 置 1，或 0 不变。

```text
15 | 10
  1111
| 1010
------
  1111
```

### 按位取反

0 变 1，1 变 0。

```text
~13 == ~1101 == 0010 == 2
```

### 按位异或

相同为 0，不同为 1。

```text
0 ^ 0 = 0
0 ^ 1 = 1
1 ^ 1 = 0
1 ^ 0 = 1
```

### 左移和右移

```text
4 << 3  -> 100 << 3  -> 100000 -> 32
5 << 2  -> 101 << 2  -> 10100  -> 20
40 >> 2 -> 101000 >> 2 -> 1010  -> 10
28 >> 3 -> 11100 >> 3  -> 11    -> 3
```

- 左移时低位补 0。
- 将一个数左移 `n` 位，变为原来的 `2^n` 倍。
- 右移时低位舍弃。

```c
value |= 1 << n;   // 将第 n 位置 1
value &= ~(1 << n); // 将第 n 位清 0
```

## sizeof 运算符

`sizeof` 的结果是一个整型表达式，用于求数据类型或变量的大小。

```c
sizeof(数据类型);
sizeof(变量名);
```

```c
int num = 100;
sizeof(int);
sizeof(num);
```

## 运算符优先级

运算符按照优先级决定表达式中各部分的运算顺序。

## 类型转换

### 自动类型转换

运算符两侧数据类型不一致时，自动向精度更高的方向转换：

```text
double > float > int > char
```

### 强制类型转换

```c
(要转换的数据类型)变量名;
```

```c
float a = 5.67;
int b = (int)a;
```

把浮点数强转为 `int` 时，小数部分会被舍弃，因此 `b` 的值为 `5`。

## 注意点

- `==` 的优先级高于 `=`。如果要先赋值再比较，应显式加括号，例如 `if ((ptr = malloc(sizeof *ptr)) == NULL)`。
- 需要无符号整型的最大值时，不要硬编码 `0xFFFF`，可使用 `UINT_MAX` 或 `~0u`。
